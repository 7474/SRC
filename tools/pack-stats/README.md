# GSC データパックの実態の集計 / Data-Pack Statistics

GSC データパックの実態（格の目安ごとの能力値・SP・性格、ユニットの能力値、数値の刻み、マップ兵器）を集計する。[7474/SRC-Data](https://github.com/7474/SRC-Data) の `docs/データ作成ガイドライン.md` の表は、このプログラムの出力から作っている。srcsharp の機能ではなく、ソリューション・CI には入れない。

## 再現

GSC データパックは [7474/SRC-Data](https://github.com/7474/SRC-Data) の `GSCデータパック` を使う。ガイドラインの表は SRC-Data のコミット `a802b31` で集計した。

```bash
git clone https://github.com/7474/SRC-Data ../SRC-Data
```

```bash
git -C ../SRC-Data checkout a802b31
```

```bash
dotnet build tools/pack-stats -c Release
```

```bash
dotnet tools/pack-stats/bin/Release/net10.0/PackStats.dll bands ../SRC-Data/GSCデータパック/拡張 > bands-ext.md
```

標準出力に Markdown、標準エラーに読み込めないファイルを出す。同じ SRC-Data・同じ引数なら同じ結果になる（ファイルの読み込み順を固定している）。

全角スペースで桁をそろえた欄・符号の後に空白がある数値を読むには、SRCCore が #1413 の修正（https://github.com/7474/SRC/pull/1415 ）を含んでいる必要がある。このプログラムは SRCCore をプロジェクト参照するので、master なら満たす。

## コマンド

```text
PackStats <コマンド> <パックのフォルダ> [引数]
```

| コマンド | 出力 | ガイドラインの節 |
|---|---|---|
| `rounding <パック>` | HP・EN・装甲・運動性・武器の攻撃力・消費 EN が刻み（100・50・10・5）に合う割合と、パイロットの能力値が 5 の倍数の割合 | 1.2 数値の刻み |
| `bands <パック>` | 経験値の帯・ザコ・汎用ごとのパイロットの能力値・経験値・SP、性格の割合、SP を持つ割合。ユニットの経験値の帯ごとのユニットの能力値（最大射程を含む）。サイズの割合。武器の攻撃力・命中補正・クリティカル率。最大射程ごとの武器の割合・最小射程・攻撃力・命中補正・移動後に使える割合と、射程 3 以上の武器を持つユニットの割合 | 1.4 性格、2.2 SP の構成、3 パイロット、4 ユニット、6.1 武器、6.2 射程 |
| `tiers <パック> <格の一覧>` | 格ごとの経験値・6 能力の合計・SP・魂か覚醒を持つ割合・強気の割合と、乗るユニットの能力値。キャラごとの一覧 | 2.1 格と実態 |
| `map <パック>` | マップ兵器を持つユニットの割合、種類（Ｍ直・Ｍ投 など）ごとの攻撃力・最大射程・EN・気力・識の割合・弾数制の割合、単体武器の最大攻撃力との比、Ｍ扇・Ｍ投の範囲のレベルごとの実態 | 5.1 マップ兵器 |
| `map-list <パック> <属性の正規表現>` | 属性が正規表現に合う武器の、ユニットの経験値の帯・識の有無ごとの集計と一覧（例: `'Ｍ投L2'`） | 5.3 マップ兵器屋 |
| `skills <パック>` | パイロットの特殊能力（レベル 30 まで）・ユニットの特殊能力を持つ割合 | 4.6 特殊能力 |
| `endurance <パック>` | 最大攻撃力の武器を 1 回の出撃で撃てる回数と、その武器の気力 | 4.7 継戦能力と切り札 |
| `growth <パック>` | 要の SP を覚えるレベル、覚えるレベルの刻み（5 の倍数の割合・間隔）、性格ごとの熱血・魂を覚えるレベル | 2.2 SP の構成 |
| `sp-mix <パック>` | SP の効果の分類（攻撃・命中・回避・防御・気力・移動・射程・行動・支援・妨害・その他）ごとの持ち方、命中・回避に効く SP の数 | 2.2 SP の構成 |
| `spread <パック>` | 同じ帯の中で得意（75% 超）・苦手（25% 未満）な能力の数、各能力の 25%〜75% の幅 | 2.4 個性の出し方 |
| `types <パック> [格の一覧]` | 同じ帯の中での位置による系統（リアル・スーパー・グレー）と、格の一覧のキャラのユニットの系統 | 4.2 系統 |
| `map-types <パック>` | マップ兵器の持たせ方の型（補助型・切り札型・マップ兵器屋） | 5.3 マップ兵器の型 |
| `sp-set <パック> [格の一覧]` | 層ごとの SP の数・最大値・消費の合計、SP ごとの持つ割合・消費・分類・覚えるレベル・レベル 1 で覚える割合、レベル 1 で覚える SP の分類、よく組み合わされる SP の対、格ごとの SP | 2.2 SP の構成 |
| `messages <パック>` | パイロットのメッセージ（`pilot_message.txt`）を持つ割合と行数、シチュエーションを持つ割合、SP 名・ヘルプに無いシチュエーション | 7 メッセージ |
| `check <パック> <作品のフォルダ>` | 作品のデータを、パックの実態と比べて総合的に評価する（下の「作品の評価」） | 8.1 作品の評価 |
| `site <出力> <GSCデータパック> [作品のルート …] [--analysis 組の評価.md …]` | GitHub Pages（Jekyll・Just the Docs）用の、作品ごとのページ（`check` の内容、組の評価を渡せば作品の組の評価・指数・レーダーチャート・総評）と一覧、トップページ。組の評価のファイル名（拡張子なし）は区分の名前（`ロボ`・`拡張`・`Sharp`）に合わせる。作品ページの front matter の `search_terms` に、サイト内検索用の名前（作品・パイロット・ユニット・武器）を入れる | - |
| `roles <組の評価の結果.md> <格の一覧>` | `tools/pack-analysis` の結果から、格ごとに決め手（S・A）を持つ割合 | 2.3 役どころの確かめ方 |

- パイロットの層: 名前に `(ザコ)`・`(汎用)` があればその層、無ければ経験値の帯（200 以上、180〜199、160〜179、120〜159、120 未満）。SP を持たないパイロット（サポートパイロットなど）は除く
- ユニットの層: ユニットの経験値の帯。武器を持たないユニットは除く
- 範囲は「25%〜75%（中央値）」。`tiers` だけ「最小〜最大（中央値）」

## 格の一覧

`tiers` に渡す、タブ区切りのファイル。`#` で始まる行は読み飛ばす。

```text
格<TAB>パイロット[<TAB>乗るユニット]
```

乗るユニットを省くと、パイロットと同じ名前のユニットを使う。

| ファイル | 内容 |
|---|---|
| `tiers-robo.tsv` | ロボ。`tools/pack-analysis/roles-robo.csv` の主人公格・準主役格・サブキャラ格（格は試作者の判断） |
| `tiers-ext.tsv` | 拡張。主要作品で格のはっきりしたキャラ（主人公格・準主役格（味方）・準主役格（ボス）・サブキャラ格） |

## 作品の評価（check）

```bash
dotnet tools/pack-stats/bin/Release/net10.0/PackStats.dll check ../SRC-Data/GSCデータパック/拡張 ../SRC-Data/Sharp/Data/幼女戦記 > check.md
```

作品のフォルダに `sp.txt` が無ければ、パックの `System/sp.txt` を先に読む。出力は次の節と、指摘の一覧。

| 節 | 内容 |
|---|---|
| パイロット | 経験値・6 能力・合計・SP の最大値の、パックの同じ層の中での位置（P）。性格の割合。得意（75% 超）・苦手（25% 未満）の数 |
| SP | SP ごとの覚えるレベルの位置と、同じ層で持つ割合。SP の数、命中・回避に効く SP の数、分類の種類、消費の合計 |
| ユニット | HP・EN・装甲・運動性・移動力・最大攻撃力・最大射程・武器数の位置、系統、最大攻撃力の武器を撃てる回数 |
| マップ兵器 | 同じ種類（Ｍ扇・Ｍ投は範囲のレベルも同じ）の中での攻撃力・射程・消費 EN・気力の位置、識の有無、型 |
| メッセージ | パイロットごとの行数と、シチュエーションの数 |
| 指摘 | 要確認（ガイドラインの目安から外れているもの）と参考（外れ値の情報） |

要確認にするもの:

- 数値の刻み（HP 100、EN 10、装甲 50、運動性 5、武器の攻撃力 100、消費 EN 5）に合わない
- 名前付きで、得意も苦手も無い
- 名前付きの SP が 6 つでない
- sp.txt に無い SP、同じ SP の重複、ザコ・汎用の SP が 4 つ以上
- 命中・回避に効く SP が 3 つ以上
- SP を覚えるレベルが全て 5 の倍数、間隔が一定
- 射程 2 以上の武器に「射」
- 経験値 120 以上の名前付きでメッセージが無い、回避・ダメージ小・中・大・破壊・攻撃のどれかが無い、SP 使用時のメッセージ（復活・自爆を除く）、ヘルプに無く武器・アビリティ・特殊能力の名前でもないシチュエーション

参考にするもの（外れ値は個性でもあり、それ自体は直す理由にならない）: ザコ・汎用の経験値・能力値・ユニットの数値の外れ値、SP の最大値・分類の種類の外れ値、SP を覚えるレベルの 5%〜95% の外、同じ層で 1% 未満しか持たない SP、珍しい性格、射程 2 で移動後に使えない武器、同じ種類の 95% を超えるマップ兵器の攻撃力、名前なし・低い帯のメッセージが無い、作品に無い武器のシチュエーション、作品のパイロットデータに無いメッセージの名前

役どころ（実効性能・単純数字の指数）は `tools/pack-analysis` で評価する。
