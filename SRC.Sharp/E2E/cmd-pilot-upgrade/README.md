# cmd-pilot-upgrade

ユニットの入れ替えと、パイロットの特殊能力・霊力・固定、ファイル名の変更を行うイベントコマンドを、ヘルプにある引数の形ごとに実行し、結果の状態を確かめる。

- Upgrade: ユニット名称指定（ランク・位置・装備アイテム・パイロットを引き継ぎ、ＨＰは全快、元のユニットは「破棄」）・対象省略・待機中のユニット（ユニットＩＤ指定、待機のまま）。ボスランクは引き継ぐ。破壊されたユニットはその場で復活する
- ClearSkill: `SetSkill` で追加した特殊能力を解除する。別名をつけて追加したもの・エリアス（`alias.txt`）で追加したもの・まだ作られていないパイロット（パイロットデータの名称で指定）
- RecoverPlana: パイロット指定で減らす・対象省略で増やす。最大霊力を越えず、0 未満にならない。霊力を持たないパイロットは何もしない
- Release: `Fix` で固定したパイロット・アイテム・デフォルトユニットのパイロットの固定を解除する（`Fix(名称)` の変数が消える）
- RenameFile: シナリオのフォルダを起点にファイル名を変える。`Dir` で元の名前が無くなり新しい名前があること、中身がそのままであることを確かめる
