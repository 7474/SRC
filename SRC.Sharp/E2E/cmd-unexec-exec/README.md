# cmd-unexec-exec

Exec コマンドで、インターミッションを通らずに別のイベントファイルを実行する。

- ステージ1（test.eve）の味方フェイズ（ターン 1）で `Exec 幕間.eve`: 出撃中の味方パイロットに追加経験値（2×SP）が入り、エピローグイベントが実行され、ステージの終わりの処理で敵ユニットは消える。Exec 以降のコマンドは実行されない
- 幕間.eve（オプションなし）はプロローグだけを実行する特殊処理用のファイルとして実行され、そこから `Exec ステージ2.eve 通常ステージ`
- ステージ2.eve は通常のステージとしてプロローグ・スタート・味方フェイズ（ターン 1）と進む
- グローバル変数で記録した実行の順序が「エピローグ → 幕間 → ステージ2」になる
