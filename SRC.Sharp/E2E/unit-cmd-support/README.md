# unit-cmd-support

支援系のユニットコマンドを、マスのクリック・メニュー・リストの選択というプレイヤーと同じ操作で行い、結果を式で確かめる。
データは Data/ の自作の最小データ（Data/System/sp.txt は basic-data から必要なスペシャルパワーだけを抜粋）。

- アビリティ（回復Lv1・補給Lv1、射程 3・援）: 対象のＨＰ+500・ＥＮ+50、使用者のＥＮ消費と行動終了（ヘルプ「アビリティ効果」）
- 修理装置Lv1: 移動後に隣接する味方へ使い、最大ＨＰの 30% 回復（ヘルプ「修理」）
- 補給装置: ＥＮを全快し、補給を受けたパイロットの気力が 10 下がる（ヘルプ「補給」）
- スペシャルパワー（ユニットのメニューから）: 「信頼」で味方を選んでＨＰを 1/3 回復、「加速」は自分にすぐ効く。ＳＰを消費し、行動は消費しない
- マップアビリティ（Ｍ全）: 効果範囲のマスを選ぶと範囲内の味方に効く
- マップコマンドの「ターン終了」: 行動していないユニットがいると確認のダイアログが出て、OK で次のターンへ進む
