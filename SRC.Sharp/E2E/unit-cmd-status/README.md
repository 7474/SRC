# unit-cmd-status

インターミッションの「ユニットステータス」の画面（Lib\ユニットステータス表示.eve）で、形態を変えるコマンドを実行し、形態とパイロットを確かめる。

- 換装: 換装先のリストから選ぶ（換装はインターミッションでのみできる。ヘルプ「換装」）
- 変形・ハイパーモード・ノーマルモード: ユニットステータスでは気力などの条件なしに切り替えられる
- 合体・分離: 2 体合体もコマンドで行い、確認なしで分離する。ステージで一度合体させてあるので、インターミッションの開始時には自動的に分離している
- インターミッションに戻って次のステージへ進める（換装した形態はそのまま）

ユニットはＨＰの大きい順に並び、形態が変わるたびに並べ直されるので、操作の前に位置を式で確かめている。
