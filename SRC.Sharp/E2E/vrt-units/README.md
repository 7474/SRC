# vrt-units

ユニットの種類ごとのステータスの欄と、戦闘の予想の画面の VRT（#1400）のためのシナリオ。`play.txt` の `snapshot` で撮った画面を、`UnitStatusVrtTests` が基準画像（`SRCRenderTests/Baselines/vrt-units-<名前>.png`）と比べる。

| snapshot | 画面 |
|---|---|
| `transform` | 変形・ハイパーモード（気力が足りず使えない色）を持つユニット。回復の地形（`Data/System/terrain.txt` の基地）にいる |
| `carrier` | 艦載機を格納した母艦のコマンドとステータス |
| `carrier-launch` | 発進するユニットのリスト |
| `combine` | 合体できるユニット（相手が隣にいる） |
| `separate` | 分離できるユニット |
| `items` | アイテムを装備したユニット。表示の指定があるアイテムだけを出し、長い名前は一行に一つ。武器を付け加えるアイテム |
| `many-features` | パイロット用特殊能力・ユニット用特殊能力・武器が多いユニット。特殊なステータスがかかっていて、減少・摩擦の地形にいる |
| `unknown` | 情報を隠した（ユニット情報隠蔽）敵ユニット |
| `ability-list` | アビリティ一覧 |
| `summoned` | 召喚したユニット（ＮＰＣ） |
| `attack-preview` | 攻撃の相手を選ぶときの予想（ダメージ・命中率・反撃） |
| `counter-select` | 敵の攻撃への対応（反撃・防御・回避）を選ぶリストと命中率の予想 |
| `counter-weapon` | 反撃に使う武器のリスト |

ステータスの欄は、マスにポインタを動かしたときに描き換わる。続けて同じマスを押すと描き換わらないので、毎回ちがうマスを押す。
画像は使わない（ユニットは名前の頭文字で描く）。
戦闘の結果は乱数で変わるので、敵のターンの初めにイベントで多機能機と標的機のＨＰ・ＥＮ・気力を元に戻す。こうして `counter-select` と `counter-weapon` の画面を毎回同じにする。
