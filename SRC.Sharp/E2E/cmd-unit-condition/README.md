# cmd-unit-condition

ユニットの状態・行動・画像・弾数・使用回数・ボスランク・封印を変えるイベントコマンドを、ヘルプにある引数の形ごとに実行し、結果の状態を確かめる。

- SetStatus: ユニット指定・対象省略・ユニットＩＤ指定。`Condition` で確かめる。行動不能のユニットは `Action` が 0 になる
- ClearStatus: ユニット指定・対象省略・ユニットＩＤ指定。かかっていない状態の指定は何もしない
- Finish: パイロット名・対象省略・ユニットＩＤ指定。２回行動のユニット（反応 200）は１回分ずつ行動を終える。行動が残っていなければ何もしない
- ChangeUnitBitmap: 画像の変更（`Info(ユニット, ID, グラフィック)` も変わる）・「-」で元に戻す・非表示・非表示解除（「非表示付加」の状態）
- SetBullet / SetStock: 名称指定・番号指定（最大弾数・最大使用回数を超える値は最大値になる）・対象省略
- BossRank: ユニット指定（ロボット基準のランク 2 は最大ＨＰが２倍、ＨＰは全快）・対象省略（ランク 0 は修正を受けないが、弾数は全快する）。適用しないユニットのボスランクは -1
- Enable: `Disable` で封印した特殊能力を、ユニット名称つき・なしで使用可能に戻す。封印されていないものの指定は何もしない
