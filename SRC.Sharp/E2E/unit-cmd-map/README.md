# unit-cmd-map

マップコマンド（空きマスの右クリックで出るメニュー）と、ユニットの一覧系コマンド・イベントで定義したコマンドを実行し、結果を確かめる。

- 作戦目的: 勝利条件イベントを実行する（メニューの表示は VB 版と同じ「作戦目的」）
- マップコマンドイベント・ユニットコマンドイベント: 追加したコマンドがメニューに出て、そのイベントを実行する（ユニットコマンドは行動を消費しない）
- 部隊表: 味方ユニット一覧からユニットを選ぶ
- 全体マップ: マップ全体と陣営ごとのユニット数を表示する
- スペシャルパワー検索: スペシャルパワーを選び、使えるパイロットを選ぶ
- ユニットの右クリック（武装一覧）、メニューの武装一覧・特殊能力一覧・アビリティ一覧
- 自動反撃モードの切り替え
- クイックセーブ → 移動 → クイックロードで移動前に戻る。リスタートでステージの開始時点に戻る
- 中断: 確認の後の保存先の選択をキャンセルするとプレイを続ける（ヘッドレスではファイル選択がキャンセルになる）
