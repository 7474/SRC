# cmd-unexec-layer

ChangeLayer・ClearLayer で上層レイヤーの地形を置いたり消したりし、マスの地形（`Info(マップ, x, y, 地形名)`・`移動コスト`）がどう変わるかを確かめる。地形は平地（0）と海（1）だけ。

- ChangeLayer: 省略時・`通常`・`情報限定` は上層の地形（海）が効き、`画像限定` は下層の地形（平地）のまま。`海(ローカル)` の `(ローカル)` は取り除いて地形名を探す。上層の海は移動コストにも効く
- ClearLayer x y: そのマスだけ。省略時はレイヤーを丸ごと、`情報限定` は情報だけを消して平地に戻る。`画像限定` は画像だけを消すので海のまま
- ClearLayer `情報限定`（座標省略）: マップ全体の上層の情報を消す。ClearLayer（引数なし）: マップ全体のレイヤーを消す
