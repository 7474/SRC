# cmd-branch-unit

ユニット・パイロットを操作するイベントコマンドを、ヘルプにある引数の形ごとに実行し、結果の状態を確かめる。

- RankUp: ユニットＩＤ指定・対象省略。変形できるユニットは他形態（Transform 後の Rank）、合体・分離できるユニットは分離ユニット／合体後の他の分離ユニットのランクも上がる
- ChangeMode: 対象省略（思考モード・座標）、陣営名・パイロット名・ユニットＩＤの指定（思考モード・座標）。`Info(ユニット, ID, 思考モード)` で確かめる
- RemoveUnit: 名前指定はパイロットの乗っていないユニットを優先し、次に乗っているユニットを削除してパイロットを降ろす（「非同期」オプション）。ユニットＩＤ指定（変形できるユニット）・対象省略・存在しないユニット
- RemovePilot: サブパイロットだけを削除するとユニットは残る。メインパイロット（「非同期」）・対象省略ではユニットも「破棄」になる。ユニットに乗っていないパイロット
- Destroy（味方フェイズ開始のイベントで実行）: パイロット名（出撃中）・ユニットＩＤ（未出撃）・既に破壊されたユニット・対象省略。敵の最後の１機を破壊すると全滅イベントが起きる
