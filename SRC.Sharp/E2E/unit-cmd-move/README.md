# unit-cmd-move

特殊な移動と召喚のユニットコマンドを、マスのクリック・メニュー・リストの選択で行い、位置・ＥＮ・陣営・状態を確かめる。

- テレポート（Lv1・ＥＮ20）・ジャンプ（Lv1・ＥＮ10）: 移動力 + レベルのマスへ移動し、ＥＮを消費する（ヘルプ「移動系特殊能力」）
- 地上・空中: 空を飛べるユニットは空中で出撃し、コマンドで地上・空中を切り替える（行動は消費しない）
- 召喚アビリティ: 隣のマスに召喚ユニット（ＮＰＣ）が出て、召喚したユニットは行動を終える
- 命令: 召喚ユニットに移動先を命令すると、ＮＰＣフェイズにそこへ移動する
- 召喚解除: 召喚ユニットが消える。解除の後はコマンド選択の状態のまま（VB 版と同じ）なので、空きマスのクリックで戻る
