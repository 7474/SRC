# unit-cmd-form

形態を変えるユニットコマンドを、マスのクリック・メニュー・ダイアログの選択で行い、形態（Unit 関数）・位置・行動数を確かめる。

- 変形: 変形先が 1 つならリストを出さずに変形し、行動は終わらない。変形イベントが起きる。変形後の移動力で移動できる
- ハイパーモード（Lv0）: 気力 100 で使え、ハイパーモード時の形態になる
- 変身アビリティ（手動解除可）: 自分だけに使う変身は行動済みにならない。「特殊モード解除」（確認のダイアログ）で元に戻る
- 3 体合体: パートナーが近くにいれば「合体」コマンドで合体し、3 人が乗る。合体イベントが起き、行動を消費する
- 分離: 確認のダイアログの後、分離後の形態の順にパイロットが乗り移る
