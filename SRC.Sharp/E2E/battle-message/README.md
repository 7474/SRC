# battle-message

戦闘中のメッセージ（`Data/テスト/pilot_message.txt`）が、状況ごとに正しく選ばれることを `expect message` で確かめる（#1400）。
5 人の攻撃役が、それぞれの相手を射程 2 から 1 回ずつ攻撃する。攻撃役には毎ターンの開始時にイベントで「必中」をかける。相手は射程 1 の武器しか持たないので反撃できない。
攻撃役の 5 人は、パイロット用特殊能力「メッセージ=攻撃役」で同じ台詞を使う。

| 相手 | 選ばれるメッセージ |
|---|---|
| ＨＰ 100% | 攻撃役の武器の名前の台詞（「攻撃」より優先）と「武器名(ダメージ)」、相手の「ダメージ小」と「射程外」 |
| ＨＰ 50% | 相手の「ダメージ中」と「射程外」（『』で囲んだ台詞） |
| ＨＰ 20% | 相手の「ダメージ大」（ダメージの後に 25% 未満） |
| ＨＰ 1% | 相手の「破壊」、攻撃役の「武器名(とどめ)」 |
| ひらめき | 相手の「回避」、攻撃役の「武器名(回避)」 |
| 敵フェイズに隣の敵が攻撃 | 敵の「攻撃」と「ダメージ小」、攻撃役の「ダメージ小」（モノローグ）と「武器名(反撃)」（`:` で区切った台詞） |

攻撃役の武器の台詞には、カットイン（`Bitmap/Event/cutin.bmp`）・ウェイト・効果音・`keep`・`clear` の区切りと、ウィンドウの幅で折り返す長い文を混ぜている。
「（使われない）」と書いた台詞は、より優先する台詞があるため出ない。

戦闘中のメッセージはクリックを待たないので、`PlayScript` は `ScreenGUI.BattleMessageShown` で表示したものを区切りごとに記録し、`expect message` はそれも探す。
