# cmd-branch-ability

UseAbility・MapAbility・SpecialPower を、ヘルプにある引数の形ごとに実行する。効果は確定値の「気力増加Lv1」（気力+10）にして、`Morale()`・`SpecialPower()`・`SP()` で確かめる。

- UseAbility: ユニット アビリティ 対象／アビリティ 対象（デフォルトユニットが使う）／ユニット アビリティ（対象は自分）／アビリティのみ
- MapAbility（Ｍ全）: ユニット アビリティ X Y（射程内の味方だけ気力が上がる）／アビリティ X Y（デフォルトユニット、範囲外の座標はマップ内に収める）
- SpecialPower: スペシャルパワーのみ（即効）／ユニット スペシャルパワー（持続）／挑発 対象（デフォルトユニットが使う）／ユニット スペシャルパワー 対象（即効・持続）。ＳＰは消費しない

スペシャルパワーは Data\System\sp.txt に定義する（友情・挑発・みがわりはテスト用）。
