# save-compat

セーブデータの版をまたぐ互換を確かめるためのシナリオ（#1357）。1 回のプレイで、3 種類のセーブを作る。

| セーブ | ファイル | いつ |
|---|---|---|
| クイックセーブ | `_quik.srcq` | 1 ターン目の味方フェイズ（ユニット・マップ・変数の状態を持つ） |
| データセーブ | `<シナリオ>までクリア.srcs` | インターミッション |
| リスタート | `_リスタート.srcq` | 2 ステージ目の始め |

グローバル変数「引き継ぎ」（42）が、どのセーブから再開しても引き継がれていることを確かめる。

- `play.txt`: 最初から最後まで進める（E2E のコーパスとしても動く）。
- `resume-<種類>.txt`: そのセーブから再開して最後まで進める手順。
- 各版のセーブは `SRC.Sharp/E2E/saves/v<版>/` にある。`SaveCompatibilityTests` が、すべての版のセーブから再開できることを確かめる。リリースのときに `tools/release.py saves` で、その版のセーブを足す。
