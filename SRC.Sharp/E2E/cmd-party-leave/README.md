# cmd-party-leave

パーティーからの離脱・復帰と、陣営の変更を行うイベントコマンドを、ヘルプにある引数の形ごとに実行し、結果の状態を確かめる。

- Leave: パイロット名（出撃中のユニットは退却して「離脱」になる）・「非同期」・対象省略・ユニット名称（パイロットの乗っていないユニット）・ユニットＩＤ（味方でないユニットは味方になって離脱する）・ユニットに乗っていないパイロット（`ForEach` の `パイロット一覧` に出なくなる）・非戦闘員（`IsAway(名称)` の変数が定義される）
- Join: パイロット名・ユニット名称・ユニットＩＤで復帰したユニットは「待機」になる。ユニットに乗っていないパイロット・非戦闘員も復帰する。対象省略はヘルプの例と同じく `ForEach 味方 離脱` の中で使う
- ChangeParty: パイロット名・対象省略・ユニットＩＤ・ユニットに乗っていないパイロット。陣営の変更で敵がいなくなっても全滅イベントは起きない
