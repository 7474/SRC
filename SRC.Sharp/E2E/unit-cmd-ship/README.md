# unit-cmd-ship

母艦・会話・チャージ・移動後の攻撃と援護攻撃を、マスのクリック・メニュー・リスト・ダイアログの選択で行い、結果を確かめる。
命中を確実にするため、味方の攻撃役には各ターンの開始時にイベントで「必中」をかける。

- 着艦: 母艦のマスへ移動すると確認が出て、OK で格納される（収納イベント）
- 格納中の回復: 1 ターンでＨＰ・ＥＮが最大値の 50% 回復する（ヘルプ「回復系特殊能力」の母艦）
- 発進: 格納しているユニットをリストから選び、母艦から移動できるマスに出して待機する
- 会話: 移動後のメニューの「会話」で隣のユニットを選ぶと会話イベントが起き、行動が終わる
- チャージ: 確認の後チャージ状態になり、次のターンにチャージ完了になって、チャージ武器（Ｃ）で攻撃できる
- 移動後の攻撃: 射程 1 の武器で移動後に攻撃する。隣にいる援護攻撃持ちの味方がサポートアタックする（ＥＮを消費し、行動は消費しない）
