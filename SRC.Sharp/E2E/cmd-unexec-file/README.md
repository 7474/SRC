# cmd-unexec-file

ファイル処理の Write・Read コマンドを、シナリオフォルダの中のファイルで確かめる。

- Write: `出力` と `追加出力` で開いたファイルに、引数ごとに引用符で囲んだ 1 行を書く（VB の `Write #` 文）。LineRead で生の行 `"ABC"` `"123"` `"カンマ,入り"` を確かめる
- Read: Write で書いたファイルを読み戻すと引用符が外れ（数値も文字列として読める）、引用符の中のカンマは区切りにならない。最後まで読むと `EOF` が 1 になる
- Read: 用意した `入力.csv`（`abc,  12  ,"x,y"` と `second line`）をカンマ区切り・前後の空白を除く・引用符で囲んだフィールド・改行区切りで読む
