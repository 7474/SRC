# cmd-branch-var

制御・変数・ファイル・描画のイベントコマンドを、引数の形ごとに実行して結果を確かめる。

- If/ElseIf: パイロット名だけの条件（出撃中・ユニットに乗っていない・出撃していない）、Not パイロット名、パイロット名でない値、括弧・変数・複数の項の式、ElseIf、入れ子、Goto 形式、Exit 形式
- CopyArray: グローバル・ローカル・サブルーチンローカルの配列と要素のない変数、コピー元の `$`・`Eval()`、コピー先の `Eval()`。コピー先の元の内容は消える
- SetSkill: 付加・上書き・別名・非表示・レベル0で削除、まだ作成されていないパイロット、エリアス（Data\テスト\alias.txt。レベル加算・乗算・-1・別名・解説）
- Print: 改行のみ・複数の語・式・`$()`・式置換・`` ` `` で囲んだ文字列・末尾の「;」で改行しない。書いたファイルを LineRead で読み戻す
- FillStyle（すべての描画方法）・PaintString（座標の有無・「-」での中央寄せ・「;」・複数の語・式置換）がエラーにならないこと（描画される文字列は SRCCoreTests の EventCmdBranchFixTests で確かめる）
