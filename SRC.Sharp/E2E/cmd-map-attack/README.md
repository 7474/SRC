# cmd-map-attack

地形・エリアの変更とマップ攻撃のイベントコマンドを、ヘルプにある引数の形ごとに実行し、結果の状態を確かめる。地形データ（`Data/System/terrain.txt`）は陸・水・屋内・月面・深水・宇宙の地形を持ち、マップの画像はこのケースのために置いた空のファイル。

- ChangeTerrain: 地形名とビットマップ番号の指定で `Info(マップ, X, Y, 地形名)`・地形クラス・ビットマップ名が変わる。「地形名(ローカル)」はビットマップ番号を負の値として扱う（`sea-0001.bmp`）
- ChangeArea: 陸（空中・地中）・水（対象省略、水中）・屋内（地上）・月面（ユニットＩＤ指定、宇宙）・深水（水上）・宇宙（宇宙）で、地形の種類ごとに指定できるエリアへ移る。`Area` で確かめる
- MapAttack: ユニット指定（「Ｍ投」で目標地点の周りのユニットを攻撃する）・座標をマップの範囲に収める・対象省略（「Ｍ全」は座標によらず自分の周り）。標的は行動不能にして必ず命中させる。使用・破壊・全滅のイベントは起きず、標的を破壊しても資金は得られない
