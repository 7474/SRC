# cmd-branch-item

RemoveItem の４通りの書式の結果を、ユニットの装備数（`CountItem(ユニット)`）と未装備の在庫数（`CountItem(未装備)`）で確かめる。

- (1) 両方省略: デフォルトユニットのアイテムをすべて外す。味方なので在庫に残る
- (2) ユニットのみ: ユニットＩＤ・ユニット名称・パイロット名で指定して外す。味方以外のユニットから外したアイテムは削除される
- (3) アイテムのみ: 装備の番号（デフォルトユニット）・アイテムＩＤ（装備中・未装備）・名称（装備されていないものを優先し、なければ装備されたもの）。存在しないアイテムはエラーにならない
- (4) ユニットとアイテム: パイロット名＋番号・ユニットＩＤ＋名称・ユニット名称＋アイテムＩＤ
