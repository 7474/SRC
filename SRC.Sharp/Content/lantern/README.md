全五話＋終話の短いオリジナルシナリオ。SRC#（SRC の C# 版）で遊ぶ。動かし方は [Content の README](../README.md) を参照。

## 生成AIの利用について

**このシナリオは生成AIを使って作られています。** 生成AIを使った作品を遊びたくない方、配布や紹介に条件のある場所へ持ち込む方は、以下を確認してください。

| 部分 | 作り方 |
|---|---|
| 原案・シナリオ・イベント・データ | 生成AI の Claude（Anthropic）が書いた |
| 顔グラフィック（`Bitmap/Pilot/Lantern_*.bmp`、12 枚） | 生成AI の PixelLab で生成した |
| ユニットの画像（`Bitmap/Unit/Lantern_*.bmp`、18 枚） | 生成AI の PixelLab で生成した |
| BGM（`Midi/`） | 生成AI の Claude（Anthropic）が作った |
| 地形の画像・地形データ・スペシャルパワーデータ・効果音・標準の BGM（`../basic-data`） | Claude が書いたプログラム（`make.py`）で描いた・合成したもの。画像生成AI・音声生成AIは使っていない（[生成法](../README.md#生成法)） |

ゲームの中でも、タイトル画面の下と「あそびかた」、終話のスタッフロールで生成AIの利用を示している。

### 生成した画像について

- 道具: [PixelLab](https://www.pixellab.ai/) の Pixen モデル（MCP の `create_image_pixen`）
- 生成した日: 2026-10-15〜16
- 入力: 英語の文章の指示だけ（画像ごとの指示は [GENERATED_ASSETS.md](GENERATED_ASSETS.md)）。既存の作品・実在の人物・他のゲームのキャラクターの画像を参考画像として渡していない。作品名やキャラクター名も指示に入れていない
- 選び方: 1 回の生成で 1 枚が出る。構図や見た目が合わなかったもの（グスタフ・ホタル・ホタルの飛行形態・ランタン号・煤帝ノクス(第一形態)・模擬戦用ダミー・灯精）は指示を変えて作り直した
- 生成後の手直し: SRC の形式に合わせる変換だけ。SRC は白を透過色として扱うため、真っ白（RGB 255,255,255）の画素を (254,254,254) に変え、ユニットの画像は透過していた背景を白にして、24 ビットの BMP で保存した。描き足し・描き直しはしていない
- 以前の版の顔グラフィック（プログラムで描いた簡単な絵）と、ユニットに使っていた `basic-data` の画像（`OBJ_*.bmp`）は、この画像に置き換えた
