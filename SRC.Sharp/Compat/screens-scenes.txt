# 画面と音の見比べ（#1553）の場面の一覧。1 行に「ID<TAB>種類<TAB>場面<TAB>実機での操作」。
# ID は screens/screens.play の snapshot の名前・画像のファイル名（<ID>.png）と同じ。種類は「画面」（スクリーンショットを取る）か「音」（耳で確かめる）。
# 実機での操作は、その場面を出すまでの操作（前の場面から続けて）。capture_screens.ps1（probe_pack.py export が書き出す）が 1 行ずつ示す。
# 並べた一覧（screens_report.py）と、CompatScreensTests（ID が screens.play と揃っているか）が読む。
