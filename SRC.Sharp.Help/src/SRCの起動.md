# SRCの起動

読み込むファイルを指定すると、タイトル画面（SRC# の版を表示します）の後にシナリオが始まります。

| 読み込むファイル | 内容 |
|---|---|
| イベントデータファイル（`*.eve`） | シナリオを最初から始めます。どのファイルが最初のファイルかはシナリオによって違うため、シナリオの Readme を見てください |
| セーブデータファイル（`*.srcs`） | インターミッションでセーブした続きから始めます |
| 中断データファイル（`*.srcq`） | マップで中断・クイックセーブした続きから始めます |

## 版ごとの起動のしかた

| 版 | 起動のしかた |
|---|---|
| SRC#Form | `SRCSharpForm.exe` を起動すると、ファイルを選ぶダイアログが開きます。ファイルを `SRCSharpForm.exe` にドラッグ＆ドロップするか、コマンドラインの引数に渡すと、ダイアログを経ずに始まります |
| SRC#Avalonia | `SRCSharpAvalonia` を起動すると、ファイルを選ぶダイアログが開きます。コマンドラインの引数にファイルを渡すと、ダイアログを経ずに始まります |
| SRC#Web | 一覧からシナリオを選びます。最初のファイルが複数あるシナリオは、選ぶ画面が出ます。セーブデータは「セーブデータから再開」に並びます |

> **元の SRC との違い**: セーブデータの拡張子は `.src` から `.srcs`（セーブ）・`.srcq`（中断）に変わりました。元の SRC のセーブデータ（`.src`）は読み込めません。
