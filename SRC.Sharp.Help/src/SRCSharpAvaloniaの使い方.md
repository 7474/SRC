# SRC#Avaloniaの使い方

対応: SRC#Avalonia（Windows・macOS・Linux）

SRC#Avalonia のウィンドウの上のメニューと、設定の方法を説明します。入手と起動は [SRC#のインストール](SRCSharpのインストール.md)・[SRCの起動](SRCの起動.md) を見てください。

## メニュー

| メニュー | 項目 | 動作 |
|---|---|---|
| ファイル | シナリオを開く... | シナリオ（`.eve`）やセーブデータを選んで始めます。前回ファイルを選んだフォルダから選べます |
| | 最初からやり直す | 今のシナリオを最初から始め直します |
| | 終了 | SRC# を終えます |
| 表示 | 100%・150%・200% | 画面の表示倍率です（下記） |
| 設定 | 設定... | 素材・表示言語・ログの設定（下記） |
| ヘルプ | ヘルプを開く | このヘルプをブラウザで開きます |
| | SRC#Avalonia の使い方 | このページを開きます |
| | SRC# のサイト | SRC# のリポジトリ（不具合の報告など）を開きます |
| | ログのフォルダを開く | ログのファイルがあるフォルダを開きます（[ログ](ログ.md)） |
| | バージョン情報 | SRC# の版とライセンスを示します |

- シナリオの途中で「シナリオを開く」「最初からやり直す」「終了」を選ぶと、セーブしていない進行状況が失われることを確かめます。
- メニューは Alt キーでも操作できます。

## 表示倍率

画面（720×496）を、ドットのまま 100%・150%・200% に拡大して表示します。選んだ倍率は次に起動したときにも使います。

- 設定が無いときは、画面に収まるいちばん大きな倍率で始まります。
- 150% は、ドットの太さが揃いません（1 画素と 2 画素が交互になります）。

## 設定

メニューの「設定」→「設定...」で開きます。設定は SRC# のフォルダの `srcs.json` に保存します。素材と表示言語は次に起動したときから、ログは保存したときから反映されます。

### 素材

| 項目 | 内容 |
|---|---|
| 拡張データフォルダ 1・2 | SRC# のフォルダとシナリオのフォルダに無いデータ・グラフィック・音楽を探すフォルダです。SRC 本体（汎用グラフィック集などを入れたもの）や開発パックのフォルダを指定します。元の SRC の Src.ini の `ExtDataPath`・`ExtDataPath2` にあたります |
| MIDI の SoundFont | MIDI を鳴らす SoundFont（`.sf2`）です。空欄なら自動で探します（[MIDIファイルのインストール](MIDIファイルのインストール.md)） |
| 素材パック | 汎用グラフィック集や開発パックなどの zip です。下記 |

- フォルダを選ぶと、中に `Bitmap`・`Data`・`Lib`・`Midi`・`Sound` のどれがあるかを示します。`Bitmap` などのフォルダそのものを選んだときは、その親のフォルダを指定するよう示します。
- 地形データ（`Data\System\terrain.txt`）などのシステムデータは、SRC# のフォルダに無ければ拡張データフォルダからも読みます。

> **元の SRC との違い**: 元の SRC は、システムデータを SRC のフォルダからだけ読みます。

#### 素材パック

汎用グラフィック集や開発パックなどの zip を、SRC# のフォルダの `Packs` フォルダに置くと、展開せずに SRC# のフォルダにあるのと同じように読みます。設定の「素材パックを追加...」で選んだ zip を `Packs` フォルダに写せます。

- zip の中の一番上に `Bitmap` などのフォルダがあれば、そのまま使います。一番上のフォルダが 1 つだけ（`汎用グラフィック集/Bitmap/…` など）なら、その中を使います。
- 複数の zip があるときは、名前順に重ね、名前が後ろのものほど優先します。SRC# のフォルダに直接置いたファイルは、素材パックより優先します。
- Windows で作った zip の日本語のファイル名も読めます。
- シナリオを始めるときに読みます。

### 表示

| 項目 | 内容 |
|---|---|
| 表示言語 | メニューや SRC# の画面の文字の言語です。「OS の言語に合わせる」も選べます。シナリオの文章は変わりません |

### ログ

| 項目 | 内容 |
|---|---|
| ログのレベル | どこまで細かく記録するかです。不具合を報告するときは Debug にします |
| ログをファイルに出す | ログをファイルに書くかどうかです |
| ログのフォルダ | ログのファイルを置くフォルダです。空欄なら既定のフォルダです |
| ログを残す日数 | 古いログのファイルを消すまでの日数です |

ログの内容と、引数・環境変数での指定は [ログ](ログ.md) を見てください。引数や環境変数でレベルを指定しているときは、そちらが優先します。

## SRC 本体と組み合わせる

SRC 本体（汎用グラフィック集・効果音集・MIDI などを入れたフォルダ）がある場合、次のどちらかで使えます。

- SRC#Avalonia の zip の中身（実行ファイルと `SoundFont` フォルダ）を、SRC 本体のフォルダにコピーする。
- SRC#Avalonia を別のフォルダに置き、設定の「拡張データフォルダ 1」に SRC 本体のフォルダを指定する。
