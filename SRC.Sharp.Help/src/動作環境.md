# 動作環境

SRC# には、遊び方に合わせて 3 つの版があります。どれも同じシナリオとデータで遊べます。入手と起動の手順は [SRC#のインストール](SRCSharpのインストール.md) を見てください。

| 版 | 動く環境 | 必要なもの |
|---|---|---|
| SRC#Web | WebAssembly のマルチスレッドに対応したブラウザ（最近の Chrome・Edge・Firefox・Safari など） | なし（ブラウザで開くだけ） |
| SRC#Avalonia | Windows（x64）・macOS（Apple シリコン・Intel）・Linux（x64） | なし（.NET を同梱した実行ファイル） |
| SRC#Form | Windows（x64） | [.NET 10 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/10.0)（x64 版） |

- SRC#Form は x64 版だけを配布しています。Arm の Windows でも x64 のエミュレーションで動くはずですが、ランタイムも x64 版が要ります（[Arm ベースの Windows PC](https://learn.microsoft.com/dotnet/core/install/windows#arm-based-windows-pcs)）。
- SRC#Avalonia と SRC#Web で MIDI を鳴らすには、SoundFont（.sf2）が要ります。SRC#Form は Windows の MIDI 出力を使います。
- 表示言語は、日本語を既定に 15 の言語から選べます。
