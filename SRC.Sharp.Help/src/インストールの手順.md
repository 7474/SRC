# インストールの手順

SRC# で遊ぶまでの流れです。

1. **SRC# を入手する**: 遊び方（ブラウザ・Windows・macOS・Linux）に合わせて、SRC#Web・SRC#Avalonia・SRC#Form のどれかを選びます。[SRC#のインストール](SRCSharpのインストール.md) を見てください。
2. **SRC のフォルダを用意する**: シナリオが使う汎用のデータ・グラフィック・効果音を置いたフォルダです。[SRCのインストール](SRCのインストール.md) を見てください。
3. **サンプルシナリオを遊ぶ**: [サンプルシナリオをプレイする](サンプルシナリオをプレイする.md)
4. うまく動かないときは [インストール時のエラーへの対処](インストール時のエラーへの対処.md) を見てください。
5. 慣れてきたら [他のシナリオをプレイする](他のシナリオをプレイする.md)、BGM を鳴らすなら [MIDIファイルのインストール](MIDIファイルのインストール.md) を見てください。

> **元の SRC との違い**: 元の SRC で必要だった VB5 ランタイムライブラリ・PNG 用の Susie プラグイン・MP3 用の VBMP3.dll は要りません。SRC# は PNG・MP3 をそのまま扱えます。
