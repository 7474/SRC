# サンプルシナリオをプレイする

SRC# の準備ができたら、サンプルシナリオを遊んでみましょう。

## 灯の巡航船ランタン号

SRC# で遊べるように作った、全五話＋終話の短いシナリオです（[SRC.Sharp/Content/lantern](https://github.com/7474/SRC/tree/master/SRC.Sharp/Content/lantern)、CC0）。素材は [SRC# の最小の汎用データ](SRCのインストール.md) を使います。

- **SRC#Web**: 一覧から「灯の巡航船ランタン号」を選ぶだけで始まります。
- **SRC#Avalonia・SRC#Form**: リポジトリの `SRC.Sharp/Content/lantern` を SRC のフォルダに置き、`01_灯の港.eve` を読み込みます。SRC のフォルダには `SRC.Sharp/Content/basic-data` の中身（または元の SRC の素材）を置いておきます。

## 元の SRC のサンプルシナリオ

元の SRC のサンプルシナリオ（チュートリアル・サンプルシナリオ・ミニキャンペーン）も遊べます。SRC 公式サイトから入手して展開し、その中の `Welcome.eve` を読み込んでください。

## 操作方法

[SRCの起動](SRCの起動.md)・[ゲームの流れ](ゲームの流れ.md)・[基本操作](基本操作.md)・[画面の説明](画面の説明.md) を見てください。

うまく動かないときは [インストール時のエラーへの対処](インストール時のエラーへの対処.md) を、遊べたら [他のシナリオをプレイする](他のシナリオをプレイする.md) を見てください。
