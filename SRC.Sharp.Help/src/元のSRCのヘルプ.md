# 元のSRCのヘルプ

元の SRC（VB 版、Ver2.2.33）に付いていたヘルプを、アーカイブとして置いています。

**[元の SRC のヘルプ（アーカイブ）を開く](/vb/index.html)**

- 元の SRC の配布物に付いていたヘルプ（CHM）の中身を、Windows 95 のヘルプに似せた画面で読めるようにしたものです。本文は、文字コードを直したほかは手を加えていません。
- 左の欄（狭い画面では「目次」のボタンで出します）に、目次・キーワード・検索のタブがあります。検索はアーカイブの中だけを探し、このヘルプ（SRC# のヘルプ）の検索には出ません。
- 本文の下の「前へ」「次へ」と、上のボタンの「<<」「>>」で、目次の順に頁を移ります。
- SRC# の動作と違うところがあります。SRC# での動作は、このヘルプの各頁と [SRCとの互換性](SRCとの互換性.md) を見てください。
- 元のファイルは [7474/SRC の SRC/HelpChm](https://github.com/7474/SRC/tree/master/SRC/HelpChm) にあります。
