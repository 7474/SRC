# 更新インストール

新しい版にするときは、[Releases](https://github.com/7474/SRC/releases) から新しい版を入手し、古いファイルに上書きします。SRC のフォルダの素材・設定（`srcs.json`）・セーブデータはそのまま使えます。

| 版 | 更新のしかた |
|---|---|
| SRC#Web | ページを開き直すと新しい版になります。追加したシナリオとセーブデータはブラウザに残ります |
| SRC#Avalonia | 新しい zip を展開し、実行ファイルを SRC のフォルダに上書きします |
| SRC#Form | 新しい `SRCSharpForm.zip` を展開し、実行ファイルと DLL を SRC のフォルダに上書きします。必要な .NET のランタイムが変わった場合は [動作環境](動作環境.md) を見て入れ直します |
