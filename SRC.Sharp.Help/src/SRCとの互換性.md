# SRCとの互換性

SRCとSRC#の互換性について。

SRC# は元の SRC（Ver.2.2.33。VB5 で作られています）の動作を正として作っています。このページには、元の SRC と動作が違うところのうち、わかっているものを載せます。わざと違えているものは、次の 2 つです。

- **元の SRC の不具合を再現しないもの**: 元の SRC のプログラムの書き誤りで、ヘルプに書かれたとおりに動かない・実行時エラーになるところは、ヘルプに書かれた（書き誤りが無ければそうなるはずの）動作にしています。
- **SRC# の利便性**: SRC# で動かすために変えたところや、使いやすくするために足したところです。

「コードから読んだもの」と書いたものは、元の SRC のプログラムを読んで判断したもので、元の SRC を実際に動かして確かめてはいません。

## プレイ
### インストール

- VB5 ランタイムライブラリ・PNG 用の Susie プラグイン・MP3 用の `VBMP3.dll` は要りません（[インストールの手順](インストールの手順.md)）。
- SRC のフォルダは、SRC# の実行ファイルを置いたフォルダです。SRC#Avalonia・SRC#Web は素材が足りなくても止まらずに動きます（[SRCのインストール](SRCのインストール.md)）。
- MIDI は、SRC#Form は Windows の MIDI 出力、SRC#Avalonia・SRC#Web は SoundFont で鳴らします（[MIDIファイルのインストール](MIDIファイルのインストール.md)）。MIDI 音源リセット（`MidiReset`）・DirectMusic・`MIDIPortID` の設定は使いません（[設定変更](設定変更.md)）。

### 操作

- SRC#Avalonia・SRC#Web では、画像の無いユニットをマップに名前の先頭の 1 文字で表示します（[マップウインドウ](マップウインドウ.md)）。
- クイックセーブのファイル名は、SRC#Form では `_クイックセーブ.srcq`、SRC#Avalonia・SRC#Web では `_quik.srcq` です（[クイックセーブ](クイックセーブ.md)）。
- MP3 を鳴らすのに `VBMP3.dll` は要りません。ＢＧＭと効果音は別々に鳴るので、MP3 の効果音で MP3 のＢＧＭが止まりません（[データ形式](データ形式.md)・[Midiフォルダ](Midiフォルダ.md)）。
- 演奏中の曲と同じ曲を指定したときは、ファイル名に英大文字を含む曲でも、最初から演奏し直さずにそのまま続けます（元の SRC は最初から演奏し直しました。コードから読んだもの）（[StartBGMコマンド](StartBGMコマンド.md)）。
- SRC#Avalonia・SRC#Web はキーボードでも操作できます。リストのウィンドウは、先頭の項目を選んだ状態で開きます（元の SRC は項目が選ばれていません）（[基本操作](基本操作.md)）。
- SRC#Avalonia・SRC#Web は、ステータスウィンドウ・メッセージウィンドウ・リストのウィンドウの文字を元の SRC と違うフォントで描くので、文字の幅や大きさが違います。空白で桁を揃えた一覧（武器・アビリティ・機体改造の一覧など）は、桁が揃わないことがあります。ポップアップメニューは画面の中に収めて開きます（元の SRC はウィンドウの外にはみ出して開きます）。
- マップのステータスに、マウスの下のマスの地形の画像を表示します。これは比べている元の SRC のソース（2012年11月25日版）のとおりで、配布された Ver.2.2.33 の Src.exe は表示しません（実機で確かめたもの）。
- ウィンドウのタイトルは「SRC# - 」とイベントファイルの名前（拡張子を除く）です。ツールチップ（マウスを置くと出る説明）は、画面からはみ出さない位置に出します。
- [RenameTermコマンド](RenameTermコマンド.md)でＨＰ・ＥＮ・ＳＰの用語を言い換えても、部隊表を並べ替えられます（元の SRC は並べ替わりませんでした。コードから読んだもの）（[部隊表](部隊表.md)）。
- 召喚したユニットが 2 体以上あるとき、どれか 1 体でも解除できれば召喚解除を出します（元の SRC は出さないことがありました。コードから読んだもの）（[召喚解除](召喚解除.md)）。
- 戦闘中のメッセージウィンドウでＨＰのゲージを動かすとき、元の SRC は書き誤りで、右のユニットについてほぼ毎回 0.16 秒待ちます。SRC# は待ちません（コードから読んだもの）。
- 画像が読めないときのエラーのメッセージは、画像のファイルごとに 1 度だけ出し、その画像は描きません（元の SRC は空の画像を描いて続けます）。メッセージのファイル名は、SRC# が探したフォルダからの相対のパスです。

### 戦闘

- 乱数の系列は元の SRC と違います。同じ乱数の種でも、命中・クリティカル・メッセージの選び方などの結果は元の SRC と同じになりません。また、元の SRC は乱数を単精度の実数で持つため、まれに `Random(最大値)` などの結果が最大値＋1 になりますが、SRC# ではなりません。
- 敵（コンピュータが動かすユニット）の思考で、元の SRC の書き誤りで働いていなかった判定を働かせます（間接攻撃の相手の選び方・移動のための変形・修理・武器の選び方・抹殺攻撃（殺属性）の期待ダメージ）。そのため、元の SRC と敵の行動が変わることがあります（コードから読んだもの）。
- マップ攻撃で母艦を破壊したとき、格納されていたユニットもすべて破壊されます（通常の攻撃で破壊したときと同じ）。元の SRC は、2 体以上格納していると 1 体おきにしか破壊しない書き誤りがあります（コードから読んだもの）。
- 活動限界による退却は 1 回だけ行います（元の SRC は、退却のメッセージと「破壊」イベントが 2 回出ることがありました。コードから読んだもの）（[SetStatusコマンド](SetStatusコマンド.md)）。
- 武器やアビリティを持つサポートパイロットが乗ったユニットで、アイテムの武器・アビリティを使い切ったときは、そのアイテムを消します。元の SRC は、1 人目のサポートパイロットの武器・アビリティを数えない書き誤りで、別のアイテムを消すことがありました（コードから読んだもの）。
- 冷属性の武器で相手をショック状態にしたときに効果音を鳴らさない判定を、攻撃に使った武器で行います（元の SRC は、反撃のときなどに別のユニットの武器を見ていました。コードから読んだもの）。

### インターミッション

- 機体改造で改造したあと、一覧をすべて作り直して表示します（元の SRC は、書き直す行の改造の費用・ランクの表示に書き誤りがありました。コードから読んだもの）。
- 換装の一覧で、最大攻撃力や最大ＨＰが 32767 を超えるユニットも、正しく表示し並べ替えます（元の SRC は値を整数（-32768〜32767）の変数に入れるので、あふれて実行時エラーになると考えられます。コードと、ほかの整数のあふれを実機で確かめた結果から読んだもの）。
- ユニットステータス・パイロットステータスで、Lib のイベントのファイルが見つからないときは、エラーを表示してインターミッションに戻ります（元の SRC は終了します）（[ユニットステータス](ユニットステータス.md)・[パイロットステータス](パイロットステータス.md)）。

### セーブファイル

SRC# は元の SRC のセーブデータ（インターミッションでセーブしたデータ・中断データ。拡張子 `.src`）を読み込めます。元の SRC で遊んでいた続きを SRC# で遊べます（[SRCの起動](SRCの起動.md)）。

- 元の SRC と同じく、中身でセーブデータか中断データかを決めます。古い版の SRC が書いたデータも、元の SRC と同じく読み替えます。
- 文字コードは、元の SRC と同じく Shift_JIS として読みます。
- 元の SRC は数値の変数も文字列としてセーブするので、読み込んだ変数は文字列の変数になります（元の SRC と同じ）。
- シナリオやマップのファイルを絶対パスで持っているデータ（シナリオのフォルダの外のマップなど）は、いまのシナリオのフォルダにある同じ名前のファイルを探します。

SRC# がセーブするデータは SRC# の形式（JSON）で、元の SRC では読めません。拡張子は `.srcs`（セーブ）・`.srcq`（中断）です。

### 設定ファイル

設定ファイルにSRCとの互換性はありません。設定は SRC のフォルダの `srcs.json` に保存されます。

- 設定変更で「戦闘アニメの拡張機能を使用する」をオフにした設定が残ります（元の SRC は書き誤りで別の名前の項目に書き込むため、残りませんでした。コードから読んだもの）（[設定変更](設定変更.md)）。

## データの作成

- ＥＣＭ のレベルがマイナスの場合、能力の説明どおり、半径３マス以内の味方ユニットに対する攻撃の命中率が増加します（元の SRC では増加しませんでした）（[回避系特殊能力](回避系特殊能力.md)）。
- ＥＣＭ の効果の範囲（半径３マス）に、上下左右に真っすぐ３マス離れた位置のユニットも入ります（[回避系特殊能力](回避系特殊能力.md)）。
- ユニット・パイロット・非戦闘員データの画像（ビットマップ）と ChangeUnitBitmap コマンドに、`.bmp` のほか `.png`・`.jpg`・`.gif` を指定できます。元の SRC では読み込めないデータになります（[データ形式](データ形式.md)・[パイロットデータ](パイロットデータ.md)・[ユニットデータ](ユニットデータ.md)・[非戦闘員データ](非戦闘員データ.md)・[ChangeUnitBitmapコマンド](ChangeUnitBitmapコマンド.md)）。
- 画像がアルファチャネルで透過を指定している場合（PNG など）、透過して表示するときは白を透過色にせず、アルファチャネルの透過を使います。ユニット画像は 256 色でなくても透過します（[データ形式](データ形式.md)）。
- 拡張データフォルダ（ExtDataPath・ExtDataPath2）の `Data\System` の battle.txt・alias.txt なども読み込みます（[バトルコンフィグデータ](バトルコンフィグデータ.md)・[エリアスデータ](エリアスデータ.md)・[Systemフォルダ](Systemフォルダ.md)）。
- レベル指定のない連属性の武器は、攻撃回数 1 回として扱います（元の SRC では攻撃時にエラーになりました）（[ダメージ算出方法に関する属性](ダメージ算出方法に関する属性.md)）。
- SRC# にはマップエディタ（MapEdit.exe）が付いていません。元の SRC に付属の MapEdit.exe を使います（[マップデータ](マップデータ.md)）。

### 元の SRC の不具合を再現しないもの

次のものは、元の SRC では書き誤りでヘルプの説明どおりに動きません。SRC# はヘルプの説明どおりに動きます（どれもコードから読んだもの）。

- アビリティの禁属性で、アビリティが使用不能になります（元の SRC では効きませんでした）（[使用可能時に関する属性](使用可能時に関する属性.md)）。
- アビリティの能力コピーで、混乱しているユニットには変化できません（[アビリティ効果](アビリティ効果.md)）。
- アビリティの強化で、強化する特殊能力にエリアスを指定したとき、エリアスの定義の各行の特殊能力を強化します（[アビリティ効果](アビリティ効果.md)）。
- ＣＴ率強化の対象武器に「!物」を指定すると、物理攻撃の武器を除きます（[武器関連特殊能力](武器関連特殊能力.md)）。
- 地形の摩擦は、ユニットのいる場所と地形のクラスが同じとき（宇宙など）にも効きます（[地形データ](地形データ.md)）。
- 特殊能力「修理不可」を持つユニットを修理できるかを、指定どおりに判定します（元の SRC は実行時エラーになることがあります）。
- スペシャルパワーの状態回復で、「〜属性使用不能」の状態も直します（元の SRC は実行時エラーになります）（[スペシャルパワーデータ](スペシャルパワーデータ.md)）。
- ダイアログデータのシチュエーションの「(対弱点=属性名)」「(対有効=属性名)」などを、メッセージデータと同じく扱います（[ダイアログデータ](ダイアログデータ.md)）。
- 特殊能力の発動などのシステムのメッセージで、`$(ユニット)` などの「～専用」の部分を、ほかのメッセージと同じく削除します（[メッセージデータ](メッセージデータ.md)）。

### そのほか

- スペシャルパワーの復活で召喚されたユニットを復活させると、召喚したユニットの召喚ユニットに戻ります（元の SRC では単独の味方ユニットになりました）（[スペシャルパワーデータ](スペシャルパワーデータ.md)）。

### データの誤り

- 元の SRC で先に進まない・実行時エラーになる・終了するデータの誤りのうち、次のものは読み込みを続けます（コードから読んだもの）。特殊能力の節の途中でファイルが終わったとき（元の SRC は空行を読み続けて先に進みません）、地形適応のデータが空のとき、スペシャルパワーの効果のレベルが数値でないとき（0 とみなします）。
- エラーのメッセージの文言が違うことがあります。2 つ目以降のデータで名称などが抜けているときは、元の SRC は 1 つ前のデータの名前を出します（SRC# は出しません）。メッセージデータの誤りでは、元の SRC は原因を空にして出します（SRC# は原因を書きます）。定義されていない地形の番号がマップデータにあるときは、マップファイルの名前を付けて出します。

（未実装機能や不具合はあります）

## シナリオの作成
### 文字コード
SRCは内部処理、各種ファイルなど全般で `Shift_JIS` コードでしたが、SRC#では全般に `Unicode` ファイルは `UTF-8` コードです。

ただし、イベントコマンドでファイルを読み書きする場合、デフォルトでは `Shift_JIS` コードで読み書きするように設定されています。

`UTF-8` コードでファイルの読み書きを行う場合はデータを含むシナリオに関するすべてのファイルの文字コードを `UTF-8` とした上で、シナリオのフォルダの設定ファイル `srcs.json`（下記）に `"SRCCompatibilityMode": false` を設定してください。

```json
{
  "SRCCompatibilityMode": false
}
```

`SRCCompatibilityMode` には `false`（読み書きとも `UTF-8`）・`true`（読み書きとも `Shift_JIS`）のほか、`"Read"`（読み込みだけ `Shift_JIS`）・`"Write"`（書き込みだけ `Shift_JIS`）も指定できます。

### シナリオのフォルダの設定ファイル

元の SRC と同じく、シナリオのフォルダに置いた設定ファイルの項目は、SRC# の設定より優先します（[設定変更](設定変更.md)）。SRC# は次の 2 つを読みます。両方にある項目は `srcs.json` を使います。

| ファイル | 形式 |
|---|---|
| `Src.ini` | 元の SRC の設定ファイルの形式です（`Shift_JIS`。`UTF-8` でも読めます）。`[Option]` の `BattleAnimation` などと `[BGM]` を使います |
| `srcs.json` | SRC# の設定ファイル（SRC# のフォルダの `srcs.json`）と同じ形式です。決めたい項目だけを書きます |

```json
{
  "SRCCompatibilityMode": false,
  "BattleAnimation": false,
  "Sections": [
    { "Name": "BGM", "Items": [ { "Name": "Opening", "Value": "はじまり.mid" } ] }
  ]
}
```

- `ExtDataPath`・`ExtDataPath2`（拡張データフォルダ）は、シナリオのフォルダの設定ファイルでは変えられません。
- プレイ中に[設定変更](設定変更.md)や自動反撃モードの切り替えで、シナリオの設定ファイルにある項目を変えると、元の SRC と同じくシナリオの設定ファイルに書き込みます。ほかの項目は SRC# の設定に書き込みます。SRC#Web では、書き込んだシナリオの設定ファイルをセーブデータと同じくブラウザにシナリオごとに残し、次にそのシナリオを開いたときも変えた設定で始めます。シナリオの設定ファイルに書き込めない場合（読み取り専用のフォルダなど）は、変えた設定はそのプレイの間だけ効きます。シナリオの `Src.ini` にある項目の値が 1 文字のときも、シナリオの設定ファイルに書き込みます（元の SRC は書き誤りで、どちらにも書き込みませんでした。コードから読んだもの）。
- SRC#・SRC#Web の設定の画面（プレイの外）で変えるのは SRC# の設定です。シナリオの設定ファイルにある項目は、そのシナリオではシナリオの設定が優先します。

### コマンド

SRCではヘルプから記載が削除されているものの、後方互換のために機能していたコマンドがあります。
それらのうち以下はSRC#では実装されていないため機能しません。

- ShowCharacterコマンド

ShowImage・ClearImage コマンドは、元の SRC と同じく動きます。

また、以下のコマンドはSRC#ではサポートされていません。

- [ClearFlashコマンド](ClearFlashコマンド.md)
- [PlayFlashコマンド](PlayFlashコマンド.md)

ほかに、次のコマンドの動作が元の SRC と違います。

- Color・Cls・ColorFilter・FillColor・PSet コマンドの色は、「#RRGGBB」のほかに「#RGB」や HTML の色の名前（Red など）でも指定できます（[Colorコマンド](Colorコマンド.md)・[Clsコマンド](Clsコマンド.md)・[ColorFilterコマンド](ColorFilterコマンド.md)・[FillColorコマンド](FillColorコマンド.md)・[PSetコマンド](PSetコマンド.md)）。Arc・Circle・Line・Oval コマンドの色は「#RGB」でも指定できます（[Arcコマンド](Arcコマンド.md)・[Circleコマンド](Circleコマンド.md)・[Lineコマンド](Lineコマンド.md)・[Ovalコマンド](Ovalコマンド.md)）。
- Arc コマンドの角度が ±360 度を超えても、エラーにせず 360 で割った余りの角度で描きます（[Arcコマンド](Arcコマンド.md)）。
- PaintPicture コマンドで画像を加工するオプション（白黒・反転・回転など）を指定したとき、画像の幅×高さが 4 の倍数でなくても描きます（元の SRC はエラーになります）（[PaintPictureコマンド](PaintPictureコマンド.md)）。
- Debug コマンドは、ログに出力します（配布された元の SRC の Src.exe では何も出力しません）（[Debugコマンド](Debugコマンド.md)）。
- LineRead コマンドは、LF だけの行の区切りでも 1 行として読みます（元の SRC は CR・CRLF だけを区切りとみなします）（[LineReadコマンド](LineReadコマンド.md)）。
- **Talk** の中の **AutoTalk**（**AutoTalk** の中の **Talk**）の行と、**End** の無い **Question** はエラーになります（元の SRC は、その行をメッセージや選択肢として表示します。Question はコードから読んだもの）（[AutoTalkコマンド](AutoTalkコマンド.md)・[Questionコマンド](Questionコマンド.md)）。
- 元の SRC で書き誤りのため実行時エラーになる次の使い方も、意図どおりに動きます（コードから読んだもの）: Join コマンドにユニットＩＤを指定する・離脱中のユニットが見つからない（[Joinコマンド](Joinコマンド.md)）、ReplacePilot コマンドで追加サポートを入れ替える（[ReplacePilotコマンド](ReplacePilotコマンド.md)）。
- ChangeTerrain コマンドで地形を変えたマスのレイヤーの画像を消さずに描き直します（元の SRC は表示から消えました。コードから読んだもの）（[ChangeTerrainコマンド](ChangeTerrainコマンド.md)）。
- ステージの途中で SaveData コマンドでセーブしたデータを読み込んだとき、味方以外・破棄されたパイロットを読み込みません（元の SRC は味方として読み込み直します。コードから読んだもの）（[SaveDataコマンド](SaveDataコマンド.md)）。
- ChangeLayer・SetWindowFrameWidth コマンドの引数の誤りのメッセージは、そのコマンドの名前で出します（元の SRC は別のコマンドの名前を出します）。
- RankUp コマンドで、最大ＨＰ・最大ＥＮが 0 のユニットのランクを変えると、ＨＰ・ＥＮの割合を 100% として扱います（元の SRC は 0 での割り算になります。コードから読んだもの）（[RankUpコマンド](RankUpコマンド.md)）。
- Open コマンドで開いたファイルは、SRCCompatibilityMode の設定によって UTF-8 で読み書きできます（[Openコマンド](Openコマンド.md)）。

### イベント・変数・関数

- システム変数 AppVersion は、互換の対象の元の SRC の版の番号 20233 を返します（[変数](変数.md)）。
- GetTime 関数は、Windows が起動してからではなく、SRC# が時間を測り始めてからのミリ秒を返します（[時間データ処理関数](時間データ処理関数.md)）。
- 正規表現関数は Windows Script ではなく .NET の正規表現を使います。Windows Script のインストールは要りませんが、細かな機能が違うことがあります（[正規表現関数](正規表現関数.md)）。
- Font 関数の「サイズ」「フォント名」は、SRC#Avalonia・SRC#Web では Font コマンドで設定した値を返します（[描画処理関数](描画処理関数.md)）。
- Option コマンドの「相手限定メッセージ等確率」は、SRC# で足したオプションです（[Optionコマンド](Optionコマンド.md)）。
- Option コマンドの「地形適応命中率修正」で、空中のユニットを地上のユニットが格闘の武器で攻撃するとき、命中率にもＪ属性の修正を加えます（元の SRC は書き誤りで加えませんでした。コードから読んだもの）（[戦闘システム詳細](戦闘システム詳細.md)）。
- 次の関数は、元の SRC の書き誤りを再現せず、ヘルプの説明どおりの値を返します（どれもコードから読んだもの）。
  - Level 関数にユニット名やユニットＩＤを指定すると、メインパイロットのレベルを返します（元の SRC は 0）（[パイロット情報関数](パイロット情報関数.md)）。
  - DiffTime 関数は経過時間を秒で返します（元の SRC は秒の桁の 0〜59 だけを返します。元の SRC の実機で確かめました）（[時間データ処理関数](時間データ処理関数.md)）。
  - Round・RoundUp・RoundDown 関数は、大きな値でも正しい値を返します（元の SRC は途中の値が 32767 を超えると、整数のあふれで実行時エラーになると考えられます）（[算術処理関数](算術処理関数.md)）。
  - InStrRevB 関数は、InStrB 関数と同じく Shift_JIS のバイト数で数えた位置を返します（[文字列処理関数](文字列処理関数.md)）。
  - Font 関数の「色」は #RRGGBB を返します（元の SRC は #BBGGRR）（[描画処理関数](描画処理関数.md)）。
- Info 関数の「特殊能力」の番号が特殊能力の数を超えるとき、空文字列を返します（元の SRC は実行時エラー）（[Info関数](Info関数.md)）。
