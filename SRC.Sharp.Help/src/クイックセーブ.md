**クイックセーブ**

マップ攻略の途中でデータをセーブします。

クイックセーブしていれば[クイックロード](クイックロード.md)を使ってクイックセーブした時点からやり直すことができます。またゲームオーバーになった時もクイックセーブ時点からやり直すことができます。

クイックセーブ実行した際にシナリオがあるフォルダの次のファイルにセーブデータが記録されます。SRCを終了してもこのファイルを読み込むことでクイックセーブ時からプレイを再開することが出来ます。

| アプリ | ファイル |
|---|---|
| SRC#Form | \_クイックセーブ.srcq |
| SRC#Avalonia | \_quik.srcq |
| SRC#Web | \_quik.srcq（ブラウザの中に保存され、シナリオを選ぶ画面の「セーブデータから再開」に並びます） |

> **元の SRC との違い**: 元の SRC のファイル名は \_クイックセーブ.src です。SRC#Avalonia・SRC#Web では \_quik.srcq になります。

シナリオ側で[**Option**コマンド](Optionコマンド.md)によりクイックセーブ不可に設定されている場合は、このコマンドは表示されません（デバッグモードのときを除く）。
