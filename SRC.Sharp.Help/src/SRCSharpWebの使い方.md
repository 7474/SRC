# SRC#Webの使い方

対応: SRC#Web（ブラウザ）

SRC#Web は、インストールせずにブラウザで遊べる SRC# です。シナリオの選び方、素材の追加、セーブデータの扱い、プレイ中のメニューと設定を説明します。開く場所は [SRC#のインストール](SRCSharpのインストール.md) を見てください。

## シナリオ選択の画面

開くと、エクスプローラーに似た画面が出ます。右に遊べるシナリオの一覧、左に操作と設定が並びます（幅の狭い画面では、操作と設定は一覧の下に出ます）。

| 場所 | 内容 |
|---|---|
| 登録済シナリオ | サイトが用意したシナリオです。名前を押すと始まります。「リンク」は、そのシナリオを直接開く URL です |
| 追加したアーカイブ | 自分で追加したシナリオ・素材の zip です（下記） |
| アーカイブを追加 | シナリオや素材の zip を追加します |
| 設定 | 言語・テーマ・操作・ログ（下記） |

最初のファイル（`.eve`）が複数あるシナリオや、セーブデータがあるシナリオでは、選ぶ画面が出ます。

| 項目 | 内容 |
|---|---|
| 文書 | シナリオに同梱の文書（Readme など）です。押すと読めます。「はじめにお読みください」が付いたものを最初に読んでください |
| セーブデータから再開 | このブラウザに残っているセーブデータです。「書き出し」でファイルとして保存し、「削除」で消します |
| 新しく始める | 最初から始めるファイル（`.eve`）です |

この画面の左の欄から、書き出したセーブデータ（`.srcs`・`.srcq`）を読み込めます。「戻る」でシナリオの一覧に戻ります。

シナリオや素材を読み込んでいる間は、読み込み中のダイアログが出ます。「キャンセル」で取り消せます。

## シナリオ・素材を追加する

手元のシナリオの zip を追加すると、このブラウザに保存され、次からも一覧から選べます。

- **シナリオ**: シナリオのフォルダを zip にしたものを追加します。
- **素材**: 汎用グラフィック集・効果音・BGM などの zip を素材として追加すると、どのシナリオでも使えます。サイトが用意した素材と同じ名前のファイルがあれば、追加したものを使います。
- **置き換え**: 同じ名前のまま別の zip に差し替えます。セーブデータは引き継ぎます。同じ名前で追加したときも上書きします。
- **MIDI**: SoundFont（`.sf2`）を、シナリオか素材の zip に入れておくと MIDI が鳴ります。どちらにも無ければ MIDI は鳴りません（[MIDIファイルのインストール](MIDIファイルのインストール.md)）。

## セーブデータ

セーブデータ（セーブ・中断・クイックセーブ）は、シナリオごとにこのブラウザに保存されます。

> **注意**: ブラウザの保存領域は、ブラウザの設定や空き容量によって消えることがあります。大事なセーブデータは「書き出し」でファイルとして保存しておいてください。別のブラウザや端末で続きを遊ぶときも、書き出したファイルを読み込みます。

## プレイ中の操作

マウス（タッチ）とキーボードで、元の SRC と同じように操作します（[基本操作](基本操作.md)）。タッチの端末では次のように操作します。

| 操作 | 意味 |
|---|---|
| タップ | 左クリック。マップでは、タップしたマスに黄色の枠（カーソル）が出ます。隣のマスに当たったときは、仮想パッドの十字キーで直して A で選べます |
| 長押し（約 0.5 秒） | 右クリック |
| 触れたまま動かす | マップのスクロール |

### 仮想パッド

マウスなどのポインティングデバイスやキーボードの無いタッチの端末（スマートフォンなど）向けに、画面の下にゲームパッドの形のボタンを出せます。タッチの端末でははじめから出ます。十字キーでマップのカーソルやメニューを動かし、A・B で決定・取り消しをするので、細かい場所をタップしなくても遊べます。

| ボタン | キー | 役割 |
|---|---|---|
| ▲◀▼▶ | 矢印キー | マップのカーソル・メニュー・リストの選択を動かす |
| A | Enter | 決定。マップではカーソル（黄色の枠）のマスを選びます。カーソルが出ていなければ、最後にタップしたマス（無ければ画面の中央）に出して選びます |
| B | Esc | 取り消し（右クリックと同じ）。押し続けると、右ボタンを押し続けたときと同じくメッセージや戦闘アニメを飛ばします |
| Z・X・Space・Ctrl・Shift | 同じ名前のキー | シナリオがキーの入力を調べるときに使う |

### システムメニュー

画面の右下の ≡ を押すと開きます。

| 項目 | 動作 |
|---|---|
| シナリオ選択へ戻る… | 確かめてからゲームを終え、シナリオ選択の画面に戻ります。セーブしていない進行状況は失われます |
| 全画面表示の切り替え | 全画面にする・戻す |
| 設定… | 表示とゲームの設定（下記） |
| 同梱の文書を読む… | シナリオに同梱の文書を読む（文書があるシナリオだけ） |
| 閉じる | メニューを閉じる |

## 設定

### プレイ中の設定（システムメニューの「設定…」）

変えたものはその場で効き、このブラウザに保存されます。

| 区分 | 項目 | 内容 |
|---|---|---|
| 表示 | 表示倍率 | 「画面に合わせる」（既定）は、ブラウザの表示領域に収まる大きさにします。100%・150%・200% は、画面の 1 ドットをその倍率の画素で表示します（100% がピクセル等倍）。表示領域より大きければスクロールします |
| | 仮想パッドを表示する | 仮想パッドを出す・隠す |
| | 選択画面を拡大して表示する | ゲームの選択肢・メニュー・確認のダイアログを、画面の下に大きなボタンでも出します。タッチの端末で押しやすくなります |
| ゲーム | 戦闘アニメを表示する など | [設定変更](設定変更.md) と同じ項目です。ゲームの中の「設定変更」で変えたものもブラウザに保存されます。シナリオの設定ファイルにある項目は、そのシナリオではシナリオの設定が優先します |
| | 自動反撃モード | 敵の攻撃への反撃を自動で選びます（[自動反撃モード](自動反撃モード.md)） |
| | MP3音量 | 音楽・効果音の音量です |
| デバッグ | ログを画面の下に表示する | ログ（[ログ](ログ.md)）を仮想パッドの下に出します。開発者ツールの無いスマートフォンでも、ログを見て不具合を報告できます。「コピー」でログを写せます |
| | ログ | ログの細かさです。Trace にすると、タップ・仮想パッド・キーの入力も記録します |

### シナリオ選択の画面の「設定」

| 項目 | 内容 |
|---|---|
| 言語 | メニューや SRC# の画面の文字の言語です。「自動」はブラウザの言語に合わせます。シナリオの文章は変わりません |
| テーマ | 画面の見た目（Windows 95・Windows XP） |
| 操作 | タッチ向け・マウス向けの画面の切り替えです。「自動」は端末に合わせます。タブレットにマウスをつないだときなどに使います |
| ログ | ブラウザの開発者ツールのコンソールに出すログの細かさです（[ログ](ログ.md)） |

## 元の SRC・ほかの SRC# との違い

- 素材のフォルダ（拡張データフォルダ）は指定できません。素材の zip を追加して使います。
- SRC#Web の設定には、`Src.ini` の `[BGM]` のように場面ごとの曲名を変える項目はありません（シナリオの zip の中の `Src.ini`・`srcs.json` は効きます。[シナリオのフォルダの設定ファイル](SRCとの互換性.md#シナリオのフォルダの設定ファイル)）。
- シナリオの設定ファイルにある項目をプレイ中の「設定変更」で変えても、ブラウザには保存しません。そのプレイの間だけ効きます。
- ログはファイルに出ません。ブラウザの開発者ツールのコンソールに出ます。プレイ中の設定で、画面の下にも出せます（[ログ](ログ.md)）。
- サイトの運営者向けの情報（自分のサイトに SRC#Web を置く方法）は、[外部のサイトに置く](https://github.com/7474/SRC/blob/master/docs/gui/web-hosting.md) を見てください。
