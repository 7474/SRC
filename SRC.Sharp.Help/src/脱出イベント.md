**脱出イベント**

ユニットがマップ端に到達したときに発生するイベント

**書式**

**脱出** *unit direction* :

**指定項目説明**

*unit*脱出するユニットの[メインパイロット名](メインパイロット名.md "ユニットに乗っているパイロットの名称または愛称のことで、イベントラベルやイベントコマンドにおいてユニットを指定するのに用います。")、ユニット名、または[陣営名](陣営名.md "ユニットがどの陣営に所属するかを現わします。")

*direction*脱出する方角

「N」(上)、「S」(下)、「W」(左)、「E」(右)で指定（全て半角文字）

**解説**

マップの*direction* 側の端にユニット*unit* が進入した場合に発生するイベントです。ユニットがマップから脱出させるイベントを再現するのに利用します。

**脱出イベント**は[**進入イベント**](進入イベント.md)に続いて発生します。

> **元の SRC との違い**: マップの四隅に進入した場合、元の SRC では左右（「W」または「E」）と上下（「N」または「S」）の両方の**脱出イベント**が発生しますが、SRC# では左右の**脱出イベント**だけが発生し、上下の**脱出イベント**は発生しません。（7474/SRC#1465）

**例**
```sh
#味方ユニットがマップ右端に侵入した場合
脱出 味方 E:
#ユニットを脱出させる
Escape
#味方数が1以上ならまだ味方がマップ上に残っている
If 味方数 > 0 Exit
#味方数が0なので脱出完了
Talk リグ
よし、全機脱出完了…撤退だ！
End
#ステージ終了
Continue Next.eve
```
