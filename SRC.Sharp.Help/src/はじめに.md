# SRC# (SRCシャープ / Simulation RPG Construction Sharp)

**SRC#（SRCシャープ）** はシミュレーションＲＰＧの自作ツールです。パイロットやユニットはもちろん、その画像やメッセージ、アイテム、効果音、ＢＧＭ、戦闘アニメの他、マップやシナリオに至るまで自由に作成することが出来ます。

## SRC# でできること

| したいこと | 使うもの | 読む頁 |
|---|---|---|
| ブラウザで遊ぶ | SRC#Web（[https://src.koudenpa.net/](https://src.koudenpa.net/)） | [SRC#のインストール](SRCSharpのインストール.md)・[SRC#Webの使い方](SRCSharpWebの使い方.md) |
| パソコンで遊ぶ | SRC#Avalonia（Windows・macOS・Linux）・SRC#Form（Windows） | [SRC#のインストール](SRCSharpのインストール.md)・[SRC#Avaloniaの使い方](SRCSharpAvaloniaの使い方.md) |
| まず遊んでみる | サンプルシナリオ「灯の巡航船ランタン号」 | [サンプルシナリオをプレイする](サンプルシナリオをプレイする.md)・[他のシナリオをプレイする](他のシナリオをプレイする.md) |
| シナリオ・データを作る | VS Code 拡張「SRC# Authoring」・`srcsharp`・SRC#Studio（マップ作成ツール・データのプレビュー） | [SRC#でシナリオ・データを作る](SRCSharpでシナリオ・データを作る.md)、書き方は「データの作成」「シナリオの作成」の各章 |
| 公開されているデータを見る・比べる | データビューア（[https://7474.github.io/SRC/](https://7474.github.io/SRC/)） | [SRC#でシナリオ・データを作る](SRCSharpでシナリオ・データを作る.md) |

質問、要望などはGitHubリポジトリ([https://github.com/7474/SRC/](https://github.com/7474/SRC/))でお願いします。

## SRC派生ソフトウェア
**SRC#** はSRC派生ソフトウェアです。

使用にあたってはSRC派生版ソフトウェアの利用における基本的規則を遵守してください。

SRC公式サイト[派生版解説ページ](http://www.src-srpg.jpn.org/development_hasei.shtml)内のSRC派生版ソフトウェアの利用における基本的規則
- [規約(形式１)](http://www.src-srpg.jpn.org/hasei_kiyaku1.html)
- [規約(形式２)](http://www.src-srpg.jpn.org/hasei_kiyaku2.html)
