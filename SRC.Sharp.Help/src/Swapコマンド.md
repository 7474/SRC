**Swapコマンド**

変数の値を入れ替え

**書式**

**Swap** *var1 var2*

**指定項目説明**

*var1*入れ替え対象の変数名

*var2*入れ替え対象の変数名

**解説**

変数*var1* と変数*var2* の値を入れ替えます。

> **元の SRC との違い**: SRC# では、値と一緒に変数の名前の情報まで入れ替えてしまうため、サブルーチンの中で[**Local**コマンド](Localコマンド.md)で作成したサブルーチンローカル変数どうしを入れ替えると値が入れ替わりません。また、入れ替えた変数が配列の要素の場合、その後の[**Sort**コマンド](Sortコマンド.md)などが正しく動かないことがあります（不具合）。（7474/SRC#1459）

**例**
```sh
Swap x y
```
