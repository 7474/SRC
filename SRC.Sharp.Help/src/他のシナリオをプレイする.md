# 他のシナリオをプレイする

SRC# では、元の SRC 向けに有志のみなさんが作ったシナリオを遊べます。シナリオは [SRC 公式サイト](http://www.src-srpg.jpn.org/) などから探せます。

気に入ったシナリオが見つかったら、配布しているサイトからシナリオの圧縮ファイルを入手します。

- **SRC#Avalonia・SRC#Form**: 適当な場所（SRC のフォルダの下など）に展開し、最初のイベントファイル（`*.eve`）を読み込みます（[SRCの起動](SRCの起動.md)）。
- **SRC#Web**: シナリオの zip を追加します。シナリオが求める素材（汎用グラフィック集など）も zip にして追加します。

![](./images/bm0.gif)シナリオは、フォルダごと展開してください。SRC のフォルダに直接展開すると、シナリオ固有のデータで汎用のデータが上書きされてしまいます。

シナリオには、内容や遊び方を書いた Readme が添付されています。まずはそれを読んでください。どのイベントファイルから始めるかも Readme に書いてあります。

多くのシナリオは演出に MIDI ファイルを使います。[MIDIファイルのインストール](MIDIファイルのインストール.md) も見てください。

> **元の SRC との違い**: SRC# は元の SRC（Ver.2.2.33）の動作を目指していますが、まだ違う所があります。わかっている違いは [SRCとの互換性](SRCとの互換性.md) を見てください。うまく遊べないシナリオがあれば、[GitHub の Issues](https://github.com/7474/SRC/issues) に報告してください。

![](./images/bm0.gif)公開されているシナリオは、シナリオの作者の責任で公開されています。シナリオによって生じた問題について、SRC# の作者は責任を負えませんのでご了承ください。
