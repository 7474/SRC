      GoToコマンド

      ラベルにジャンプ

      書式

      GoTo label

      指定項目説明

      labelジャンプ先のラベル名。「:」は不要

      解説

      ラベルlabel にジャンプしてコマンドの実行の流れを変更します。

      label にイベントラベルを指定するときはラベルを必ず「"」で囲ってください。

      GoToコマンドでForループやサブルーチン内にジャンプして入ったり(出たり)するとループの動作がおかしくなります。このようなジャンプはしないようにしてください。
