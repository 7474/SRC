      Incrコマンド

      変数の値を増加

      書式

      Incr variable [value]

      指定項目説明

      variable変数名

      value値の増加量（省略可）

      解説

      変数variable の値を value だけ増加させます。value にマイナスの値を指定して値を減少させることもできます。value を指定しなければ変数の値が 1 だけ増加されます。

      variable がいままでにSetコマンドやIncrコマンドの対象になっておらず、まだ作成されていない場合は変数variable が自動的に作成されます。この際、variable はそのマップ中にのみ有効なローカル変数になります。複数のステージに渡って有効な変数を作成したい場合にはあらかじめGlobalコマンドを使用ておいて下さい。
