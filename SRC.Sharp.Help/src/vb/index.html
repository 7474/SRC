SRC Ver2.2.33 ヘルプ（アーカイブ）

元の SRC（VB 版、Ver2.2.33）に付いていたヘルプのアーカイブです。データ・イベントの書き方を元の SRC と比べるときなどに使ってください。 SRC# の使い方と、SRC# での動作は SRC# のヘルプ を見てください。
