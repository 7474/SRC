# インストール時のエラーへの対処

よくある症状と対処です。

## SRC#Form が起動しない

[.NET 10 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/10.0) の x64 版が入っているか確かめてください。Arm の Windows でも x64 版が要ります（[動作環境](動作環境.md)）。

## SRC#Avalonia が起動しない

- **macOS**: 署名していないため、初回は Finder で右クリックして「開く」で起動してください。
- **Linux**: 実行できない場合は、実行権限を付けてください（`chmod +x SRCSharpAvalonia`）。

## SRC#Web が始まらない

WebAssembly のマルチスレッドに対応した、最近のブラウザ（Chrome・Edge・Firefox・Safari など）を使ってください（[動作環境](動作環境.md)）。

## 「Bitmapフォルダがありません」「フォルダ構造を直してください」などと表示される

SRC のフォルダの中身が足りないか、形が違います。[SRCのインストール](SRCのインストール.md) のフォルダ図と見比べてください。

- SRC#Form・SRC#Avalonia は、**実行ファイルを置いたフォルダ**を SRC のフォルダとして使います。実行ファイルを SRC のフォルダにコピーしてください。
- 素材の zip を展開したときに、`Bitmap\Bitmap` のようにフォルダが二重になっていないか確かめてください。

## 画像が表示されない（SRC#Avalonia・SRC#Web）

SRC#Avalonia・SRC#Web は、素材が足りなくてもエラーにせずに進みます。シナリオが求める素材（汎用グラフィック集など）が SRC のフォルダにあるか確かめてください。

## BGM（MIDI）が鳴らない

[MIDIファイルのインストール](MIDIファイルのインストール.md) を見てください。SRC#Avalonia・SRC#Web は SoundFont（.sf2）が要ります。SRC#Web は、画面を最初にクリック（またはキーを押す）してから音が鳴ります。

## それ以外のエラー

[GitHub の Issues](https://github.com/7474/SRC/issues) に、使っている版（SRC#Web・SRC#Avalonia・SRC#Form）と OS、シナリオ、症状をできるだけ詳しく書いて報告してください。
