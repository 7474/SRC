# アンインストール

SRC# はレジストリへの書き込みやシステムフォルダへのコピーを行いません。

| 版 | アンインストールのしかた |
|---|---|
| SRC#Avalonia・SRC#Form | 実行ファイル（SRC#Form は DLL も）と、SRC のフォルダの `srcs.json` を削除します。SRC のフォルダごと削除してもかまいません |
| SRC#Web | ブラウザのサイトのデータ（SRC#Web のページの保存データ）を削除すると、追加したシナリオとセーブデータが消えます |

SRC#Form のために入れた .NET デスクトップ ランタイムが不要になった場合は、Windows の「アプリ」から削除します。
