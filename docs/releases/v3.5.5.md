SRC# 3.5.5 です。アプリは `3.5.5`、ライブラリ・ツールと VS Code 拡張は `0.5.5` です（[バージョンの管理](https://github.com/7474/SRC/blob/master/docs/versioning.md)）。

味方フェイズを自動で進めるマップコマンド「オートプレイ」を加えました。元の SRC と動きが違っていた点（FadeOut・WhiteOut の後の画面、全角の数値など）を直しています。

## 動きが変わる点

どれも元の SRC に合わせたものです。SRC# 3.5.4 までの動きに合わせて作ったシナリオでは、見え方や結果が変わることがあります。

- FadeOut・WhiteOut の後は、塗りつぶした画面のままにします。これまでは暗転前の画面に戻していたため、続けて描いた PaintPicture・PaintString と一緒に暗転前の画面が見えていました。暗転前の画面に戻すには ClearPicture を使います（#1329）。
- 数値の前後の全角の空白と、全角の数字を半角として読みます。データの「　1400」「１４００」は 1400 です。これまでは数値と判定したのに 0 として読み、エラーも出していませんでした。「1400　1」のように間に空白があるものは数値ではありません（#1326）。
- イベントで定義したユニットコマンド・マップコマンドは、メニューに 10 個まで出します（#1333）。
- 同じイベントファイルを二度読み込みません。Require や include で重ねて読み込んだとき、常時イベントが 1 回のイベントで何度も動いていました（#1333）。

## 主な変更

- **オートプレイ**: マップコマンド「オートプレイ」を選ぶと、味方フェイズを敵と同じ思考ルーチンで進め、ターンを終えます（#1289）。
  - もう一度選ぶまで、次の味方フェイズも続けます。敵の攻撃への反撃・防御も自動で選びます。
  - 味方フェイズの間に右ボタンを押すと、ユニットの行動の切れ目で止まります。残りは自分で操作できます。
  - 敵・中立・ＮＰＣがマップにいなくなったら止まります。設定ファイル・セーブデータには残しません。
  - ヘルプに[オートプレイ](https://srch.7474.jp/オートプレイ/)の頁を加えました。
- **不具合の修正**
  - 移動のアニメーションの後に、移動したユニットが消えることがあったのを直しました（#1319）。
  - ステータス画面に、「非表示」を指定した特殊能力や、ＢＧＭ・吸収など常に表示しない特殊能力が出ていたのを直しました（#1333）。
  - Wait Click の直後のクリックを取りこぼすことがあったのを直しました（#1301）。
  - 環境変数 `SRCSHARP_FONTS` で太字だけのフォントのファイル（`NotoSansCJK-Bold.ttc` など）を指定すると、標準の太さの文字も太字で描いていたのを直しました（#1327）。
- **SRC#Web**
  - マップの描画と、ファイルを探す処理を速くしました。「灯の巡航船ランタン号」を選んでから最初の入力待ちまで、約 3.1 秒から約 2.4 秒になりました（#1288）。
  - 版ごとに URL が変わるカタログ（SRC#Site の共有パックなど）で、古い版の zip をキャッシュから消します（#1338）。
  - アーカイブを「置き換え」た後に、一覧の「削除」が置き換える前のものを指していたのを直しました（#1292）。
- **データビューア**
  - 置いたサイトの zip（シナリオ・素材・共有パック）のデータ・画像・音を見られます。サイトの `viewer.json` に一覧（`archiveIndexes`）を書くと、メニューに「アーカイブ」が出ます（#1338、[データビューア](https://github.com/7474/SRC/blob/master/docs/gui/dataviewer.md)）。
  - MIDI を SoundFont で合成して鳴らします。パイロットの BGM とユニットの特殊能力「ＢＧＭ」は、その場のボタンで鳴らせます。画面を移っても鳴り続け、画面の下の「止める」で止めます（#1338）。
- **シナリオの確かめ（SRCLintWeb）**: `srcsharp lint` と同じ検査を、ブラウザの中で動かせるようにしました。SRC#Site の投稿の画面で、上げる前に使っています（#1315・#1317・#1325）。
  - Call・Goto の飛び先のラベルと、include するファイルがあるかも確かめます。
  - 画像・音・マップのファイルが、シナリオや一緒に使う素材の zip にあるかを知らせます。戦闘アニメの `;` 区切りと、特殊能力の `ＢＧＭ=曲.mid` の形も読みます（#1316・#1346）。
- **その他**
  - SkiaSharp を 4 に、SRC#Form の NAudio を 3.3.0 に上げました（#1312・#1313・#1347）。
  - CI が通れば Dependabot の更新を自動でマージする構成にしました。CI から Percy・Cypress Cloud・Codecov を外しました（#1286・#1299・#1301）。
  - ドキュメントを現状・判断の記録・履歴に分け、フロントエンドのサポートの階層を決めました（#1306・#1340・#1342）。
  - 依存パッケージを更新しました（#1294・#1295・#1296・#1298・#1302・#1314・#1318・#1320・#1321・#1322・#1336・#1343・#1344・#1345）。
