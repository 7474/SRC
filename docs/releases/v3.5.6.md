SRC# 3.5.6 です。アプリは `3.5.6`、ライブラリ・ツールと VS Code 拡張は `0.5.6` です（[バージョンの管理](https://github.com/7474/SRC/blob/master/docs/versioning.md)）。

デスクトップ版の SRC#Avalonia に、ファイル・表示・設定・ヘルプのメニューを加え、設定をメニューからまとめて変えられるようにしました。MIDI 用の SoundFont を同梱し、起動してすぐに音が鳴ります。ステータス・データの読み込み・敵の思考などで元の SRC と動きが違っていた点も直しています。

## 動きが変わる点

どれも元の SRC に合わせたものです。SRC# 3.5.5 までの動きに合わせて作ったシナリオでは、見え方や結果が変わることがあります。

- データの項目の前後の全角の空白を取り除いて読みます。「　 -」は「-」、「 AABA」は「AABA」です。「- 10」「+ 20」のように符号の後に空白がある値も数値として読みます。GSC データパックのように全角の空白で桁を揃えたデータで、地形適応・クリティカル率・属性がずれて読まれていました（#1415）。
- `Data\System\alias.txt`（シナリオのものを優先し、無ければ SRC# のもの）を読み込みます。これまでは読んでいなかったため、そこで定義したエリアスが使えず、エリアスで非表示にした能力がステータスに出ていました。換装・パーツ合体・ノーマルモードは、元の SRC と同じく非表示でもユニットステータスのコマンドに出します（#1429）。
- ステータスの顔の絵・メッセージの欄・ＨＰとＥＮのゲージなどに、元の SRC と同じへこんだ 2 ドットの枠を描き、絵とゲージを枠の内側に出します。顔の絵は 64×64 のまま出ます（これまでは 68×68 に引き伸ばしていました）。ゲージの長さも元の SRC と同じく内側の幅で切り捨てます（#1430）。

## 主な変更

- **SRC#Avalonia（デスクトップ版）**
  - メニューを加えました。「ファイル」でシナリオを開く・最初からやり直す・終了、「表示」で表示倍率、「設定」で設定のウィンドウ、「ヘルプ」でヘルプ・使い方・ログのフォルダ・バージョン情報を開けます（#1437）。
  - 設定のウィンドウで、素材（拡張データフォルダ・SoundFont・素材パック）・ゲーム（元の SRC の設定変更と同じ項目・音量）・BGM（場面ごとの曲。元の SRC の `Src.ini` の `[BGM]` を取り込めます）・表示言語・ログを変えられます。シナリオを作る人向けの設定（デバッグモードなど）は「設定」の「開発者向けの設定...」で変えます（#1435・#1439・#1440）。
  - 表示倍率を 100%・150%・200% から選べます。設定が無ければ、画面に収まるいちばん大きな倍率にします（#1426・#1434）。
  - 汎用グラフィック集などの zip を、展開せずに素材パックとして読めます。設定の「素材パック」で加えます（#1436）。
  - MIDI を鳴らす SoundFont を同梱しました。SoundFont を用意しなくても MIDI が鳴ります（#1435、[MIDIファイルのインストール](https://srch.7474.jp/MIDIファイルのインストール/)）。
  - 配布物で OpenAL を読めず、音が鳴らないことがあったのを直しました（#1439）。
  - MS ADPCM・IMA ADPCM・μ-law・A-law の WAV の効果音が鳴らなかったのを直しました。素材パックの中の効果音も探します（#1441）。
  - 拡張データフォルダの地形データ（`terrain.txt`）を読まず、マップチップが出ないことがあったのを直しました（#1436）。
  - 前回シナリオを選んだフォルダから選べます（#1435）。
  - メニュー・設定のウィンドウの文字を OS の大きさに合わせました（#1442）。
  - Windows（ARM64）版 `SRCSharpAvalonia-win-arm64.zip` を加えました（#1433）。
  - ヘルプに [SRCSharpAvaloniaの使い方](https://srch.7474.jp/SRCSharpAvaloniaの使い方/) の頁を加えました。
- **不具合の修正**
  - 敵が回復アビリティを選ぶときに、止まることがあったのを直しました（#1405）。
  - 変身するアビリティで、変身先の追加パイロットではなく、使った相手のものを作っていたのを直しました（#1405）。
  - 追加パイロットとパイロット能力付加を持つユニットにパイロットを乗せる、制御不可で暴走時パイロットを持つユニットを出撃させる、などで止まることがあったのを直しました（#1410・#1412）。
  - 愛称変更・パイロット愛称の式が自分の愛称を参照すると、止まっていたのを直しました（#1414）。
  - ステータスの欄に、毒・麻痺などの状態、武器強化付加などの付加、ダミーなどが出ていなかったのを直しました。発進のリストの空白も元の SRC に合わせました（#1409）。
  - 戦闘中のメッセージの欄で、ＨＰ・ＥＮが減っていく途中に小数点つきの値が出ていたのを直しました。途中の値も元の SRC と同じ丸め方にしました（#1427・#1431）。
  - 戦闘中のメッセージの欄で、前の攻撃のユニットの絵が残り、入れ替わって見えることがあったのを直しました（#1428）。
  - 中断・クイックセーブ・リスタートのデータを、シナリオのフォルダを移すと再開できなかったのを直しました。3.5.5 までのセーブも、いまのシナリオのフォルダから探して再開します（#1387）。
- **SRC#Web**
  - 画面をブラウザの表示領域に収まる大きさにしました。システムメニューの「表示倍率」で、ピクセル等倍（100%）〜400% も選べます（#1426・#1434）。
- **開発版**: master に入るたびに、開発版（`3.5.6-dev.<番号>`）を GitHub の `dev` のプレリリースと Docker Hub の `koudenpa/srcdatalinter:dev` で出します（#1419、[バージョンの管理](https://github.com/7474/SRC/blob/master/docs/versioning.md)）。
- **その他**
  - 戦闘の計算・敵の思考・セーブの版をまたぐ互換・画面の VRT など、リグレッションを防ぐテストを加えました（#1366・#1376・#1380・#1381・#1382・#1393・#1402・#1403・#1408）。
  - CI の待ち時間を縮め、配る物を push ごとに作って確かめるようにしました（#1367・#1368・#1374・#1379・#1383・#1384・#1385・#1391・#1432）。
  - データビューアのプロジェクトの名前を改め、役目を終えたコード・ツールを消し、運用の全体像を文書にしました（#1349・#1392）。
  - GSC データパックのバランスの集計・評価のツール（`tools/pack-stats`）を加えました（#1401・#1416・#1417・#1420・#1421）。
  - VS Code 拡張のテストを加えました（#1386）。
  - 依存パッケージを更新しました（#1370・#1373・#1389・#1390）。
