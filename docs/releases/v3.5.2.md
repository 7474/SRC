## 主な変更

- **VS Code 拡張 0.5.1（正式版）**: [koudenpa.src-vscode](https://marketplace.visualstudio.com/items?itemName=koudenpa.src-vscode) を正式版として公開しました。拡張機能ビューから入れる・更新するだけで入ります（#1220）。
  - デバッグ中のシナリオを「SRC# 画面」のタブで遊べます。画面をクリック・キーで操作でき、ブレークポイントで止めると画面も止まります。
  - ホットリロード: イベント・データ・画像を保存すると、プレイの状態（ユニット・マップ・変数・ターン）を保ったまま読み直します。
  - 操作パネルと設定画面を加えました。srcsharp が見つからない時は、拡張から入れられます。
  - イベント・データの既定の文字コードを UTF-8 にしました。Shift_JIS のファイルは自動判別で開きます。
- **srcsharp 0.5.2**: VS Code 拡張の画面とホットリロードに対応しました。`srcsharp --version` を加えました。デバッガは SRC 本体のフォルダの共通の素材と Lib を読みます。更新するには `dotnet tool update -g SRCSharpTools` を実行します。
- **SRC#Web**
  - タッチの端末で操作しやすくしました。押しやすい大きさの画面、大きなボタンの選択画面、仮想パッドだけでの操作、指を滑らせてのマップのスクロールに対応しています（#1193・#1198・#1199・#1209）。
  - シナリオ選択の画面をエクスプローラー風にし、Windows 95・XP のテーマを切り替えられるようにしました（#1195）。
  - 遊べるシナリオ「灯の巡航船ランタン号」を組み込みのカタログで配信します（#1197・#1213）。
  - カタログのアーカイブをブラウザにキャッシュし、素材のアーカイブの SoundFont でも MIDI を鳴らすようにしました。大きいシナリオでのメモリの使用量を減らし、落ちる不具合を直しました（#1190・#1192・#1194）。
- **表示**: メッセージウィンドウを元の SRC と同じくメインウィンドウに重ね、拡大表示を切り替えにしました。クリック待ちのポインタ、PaintString などで描いた内容の反映も元の SRC に合わせました（#1189・#1210・#1211）。
- **移植の修正**
  - 戦闘の結果が変わるもの 57 件を直しました。耐性・指揮・武器レベル・丸め・移動などです（#1215）。
  - 表示・コマンド・イベント・セーブなど、残りの 64 件を直しました（#1216）。
  - Linux・ブラウザでリスタート・中断データから再開できない不具合を直しました（#1196）。
  - マップ・RemoveUnit・ReplacePilot・Oval・FontCmd などの不具合を直しました（#1184・#1191）。
- **Option**: 「相手限定メッセージ等確率」を加えました（#1187）。
- **テスト**: E2E でのコマンドの網羅を広げ、CI でコマンドのカバレッジを集計します。SRCCore のテストも補強しました（#1214・#1217）。
