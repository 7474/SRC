SRC# 3.5.4 です。アプリは `3.5.4`、ライブラリ・ツールと VS Code 拡張は `0.5.4` です（[バージョンの管理](https://github.com/7474/SRC/blob/master/docs/versioning.md)）。

| | 入手 |
|---|---|

## 主な変更

- **SRC#Web**
  - シナリオの読み込み中は、今の処理と進み具合を出します。「キャンセル」で取り消すと、シナリオの選択に戻ります（#1270）。
  - 追加したアーカイブを「置き換え」で別の zip に差し替えられます。セーブデータは引き継ぎます。同じ名前で追加すると上書きします（#1270）。
  - シナリオに同梱された文書（.txt・.md・.htm(l)）を読めます。.eve を選ぶ画面の「文書」と、プレイ中のシステムメニューから開きます。文字コード（UTF-8・Shift_JIS）は自動で判別します（#1270）。
  - 利用者が追加した素材を、サイトが配る素材より優先するようにしました。手元の BGM などで差し替えられます（#1280）。
  - サイトを置く人向けに、次の設定を加えました（#1280）。
    - 年齢の区分（`rating`）と、始める前に確かめる設定（`ratingConfirm`）
    - シナリオ・素材の追加を止める設定（`allowUserScenarios`・`allowUserAssets`）
    - `?play=<id>` で開くときにそのシナリオのカタログだけを読む設定（`playCatalog`）
  - macOS・Linux で作った zip の日本語のファイル名が文字化けしていたのを直しました（#1281）。
  - プレイを始めるとき・再開するときに、まれにエラーで止まっていたのを直しました（#1266）。
- **シナリオの作成**
  - シナリオのフォルダにイベントファイルがたくさん並ぶと、どれを開けばよいか分からなくなります。入口のファイルだけを直下に置き、章をサブフォルダに分けた構成でも、章を単体で実行・デバッグできるようにしました（#1282）。
    - `srcsharp play` の `--scenario-root` と launch.json の `scenarioRoot` で、シナリオのフォルダを指定できます。
    - 指定しなければ、開いたファイルのフォルダに `Data` が無いとき、`Data` のあるいちばん近い親フォルダを使います。
    - 「灯の巡航船ランタン号」もこの構成にしました。直下は入口の `01_灯の港.eve` だけです。
  - Load コマンドで読み込んだ作品を、元の SRC と同じく作品の一覧に登録します。同じ作品を二度読み込まなくなりました（#1268）。
  - シナリオの読み込み（ラベルの登録）と、マップ・画面の描画を速くしました（#1269）。
- **不具合の修正**
  - Windows で、クイックセーブの後にクイックロードできなかったのを直しました（#1277）。
- **srcsharp 0.5.4**
  - `srcsharp help <項目>` で SRC# のヘルプ（428 ページ）を引けます。`--search` で、関連の高い順に探せます（#1265）。
  - `srcsharp play --skip-wait` で、アニメーションやメッセージの表示時間などの待ちを飛ばして速く進みます（#1267）。
  - `srcsharp play` の自動プレイを直しました（#1276・#1279）。
    - 敵へ寄る方針（`policy advance`）で、今いるマスへの移動を選んで止まることがなくなりました。
    - `expect message` が、画面の折り返しをまたぐ文字列も照合します。
- **VS Code 拡張 0.5.4**
  - 「開いているイベントを自動プレイ（画面付き・早送り）」を加えました。`.play` スクリプトを選ぶか、スクリプト無しで、「SRC# 画面」タブにプレイの様子を出して早送りで進めます（#1279）。
  - launch.json の属性を加えました。
    - `skipWait`・`policy`・`turns`（#1279）
    - `scenarioRoot`（#1282）
    - スクリプト無しの自動プレイでも、味方フェイズを動かして戦闘を進めます。
  - スクリプトや自動プレイで動かすときも、画面を表示が変わるたびに送ります（#1279）。
- **その他**
  - CI のテストを足し、Web の E2E テストの不安定さを抑えました（#1278・#1284）。
  - 依存パッケージを更新しました（#1271・#1272・#1274・#1275）。
