SRC# 3.5.3 です。アプリは `3.5.3`、ライブラリ・ツールと VS Code 拡張は `0.5.3` です（[バージョンの管理](https://github.com/7474/SRC/blob/master/docs/versioning.md)）。

## 遊ぶ

| | 入手 |
|---|---|
| ブラウザ | **SRC#Web** https://7474.github.io/SRC/web/ 。自分のサイトに置くための `SRCSharpWeb.zip` も添付しています（[外部のサイトに置く](https://github.com/7474/SRC/blob/master/docs/gui/web-hosting.md)） |
| Windows・macOS・Linux | **SRC#Avalonia** `SRCSharpAvalonia-<OS>.zip` |
| Windows（x64） | **SRC#Form** `SRCSharpForm.zip`（[.NET 10 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/10.0) の x64 版が必要） |

## 主な変更

- **SRC#Web を速くしました**: 「灯の巡航船ランタン号」を選んでから始まるまでの時間が、約 4.5 秒から約 2.2 秒になりました（#1262）。
  - ファイルを探す処理（大文字・小文字を区別しないパスの解決）が、無いファイルを探すたびにフォルダの一覧を作り直していたのを直しました。SRC#Form・SRC#Avalonia にも効きます。
  - AOT コンパイルするようにしました。その分、最初のダウンロードは増えます（約 6 MB → 約 11 MB）。
- **ログ**: アプリ・ツール全体でログを整えました（#1259）。不具合を報告するときは、ログのファイルを添えてください（[ログ](https://srch.7474.jp/ログ/)）。
  - SRC#Form・SRC#Avalonia・srcsharp は、ログをファイルに残します。場所は、Windows は `%LOCALAPPDATA%\SRCSharp\logs`、macOS は `~/Library/Logs/SRCSharp`、Linux は `~/.local/state/srcsharp/logs` です。
    - SRC#Form は、これまでの「実行ファイルのフォルダの `logs`」から移りました。
  - レベルは、引数（`-v`・`-vv`・`--log-level`）、環境変数（`SRCSHARP_LOG_LEVEL`）、設定ファイル（`srcs.json` の `Log` セクション）で変えられます。
  - SRC#Web は、URL の `?log=Debug` とシステムメニューの設定でレベルを変えられます。
  - エラーがログに記録されていなかった不具合を直しました。
- **音**
  - SRC#Web: ランタン号で MIDI の BGM が鳴ります。SoundFont（TimGM6mb）を素材として重ねます（#1256）。
  - SRC#Form: MIDI の再生ライブラリ（DryWetMidi）を 8.0.3 に更新しました（#1255）。
    - 曲の頭で MIDI 音源を初期化し、前の曲のピッチベンドなどが残らないようにしました。
    - 使わない「MIDI 音源リセット」の設定を設定画面から外しました（#1254）。
  - 素材の無い環境で使う `basic-data` に、効果音 54 種類と標準の BGM 11 曲を加えました。プログラムで合成したもので、生成 AI は使っていません（#1257）。
- **表示**
  - SRC#Web・SRC#Avalonia: 画面を拡大して表示するときは、補間せずドットのまま拡大します（#1246・#1247）。
  - SRC#Form: 文字列を余白なしで測って描き、区切りごとに空いていた間をなくしました（#1245）。
  - 仮想パッド・矢印キーでマップカーソルを動かしたとき、ユニットのいないマスでは、カーソルのマスの地形を出すようにしました（#1261）。
- **データ・イベント**
  - ユニット・パイロット・非戦闘員の画像と ChangeUnitBitmap に、PNG・JPEG・GIF を使えます。アルファチャネルの透過を優先します（#1241）。
  - レベルがマイナスのＥＣＭで、能力の説明どおり命中率が上がるようにしました（#1240）。
  - セーブデータのファイル名の拡張子 `.src` を、SRC# の拡張子（`.srcs`・`.srcq`）にします。`〜.src.srcs` のような名前にならなくなりました（#1252）。読み込めないファイルのエラーでも、SRC# の拡張子を案内します（#1250）。
- **SRC#Web**
  - シナリオやセーブデータを読み込んでいる間は、ほかの操作を受け付けません（#1260）。
  - セーブデータのブラウザへの保存を、1 秒ごとの走査から、書き込んだときの通知に変えました（#1242）。
- **VS Code 拡張 0.5.3・srcsharp 0.5.3**
  - 拡張のアイコンを加え、アクティビティバーのアイコンを「SRC#」にしました（#1251）。
  - WSL で使うとき、画面の日本語に Windows のフォント（ＭＳ ゴシック・ＭＳ 明朝）を使います。日本語のフォントが無ければ、デバッグの開始時に知らせます（#1253）。
  - 設定 `srcsharp.logLevel` と launch.json の `logLevel` を加えました。Language Server のログは出力パネルの「SRC#」に、デバッガのログはデバッグコンソールに出ます（#1259）。
  - デバッガの画面の送信で、接続が切れた後にプロセスが落ちる不具合を直しました（#1244）。
- **ヘルプ**: SRC# の入手・インストールの手順と動作環境、編集方針、「ログ」のページを加えました。If コマンドの説明を実装に合わせました（#1237・#1248・#1249・#1239）。
- **その他**
  - 不具合の報告用の Issue テンプレートを加え、ログの欄を設けました（#1235・#1259）。
  - CI の警告を直し、所要時間を縮めました（#1236）。依存パッケージを更新しました。
