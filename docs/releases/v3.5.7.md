SRC# 3.5.7 です。アプリは `3.5.7`、ライブラリ・ツールと VS Code 拡張は `0.5.7` です（[バージョンの管理](https://github.com/7474/SRC/blob/master/docs/versioning.md)）。

元の SRC（Ver.2.2.33。VB5）の 1,333 の手続きをすべて SRC# と突き合わせ、違っていた所を元の SRC に合わせました。さらに元の SRC の実機で動かした結果と比べて、数値の読み方・Format・エラーの出し方などを合わせ、画面と音も実機と見比べました。元の SRC のセーブデータ（`.src`）も読めるようになりました。

## 動きが変わる点

どれも元の SRC に合わせたものです。SRC# 3.5.6 までの動きに合わせて作ったシナリオでは、見え方や結果が変わることがあります。わざと元の SRC と違うままにしている点は、ヘルプの [SRCとの互換性](https://srch.7474.jp/SRCとの互換性/) にまとめました（#1576）。

- **名前の比べ方**: 変数名・ラベル・ユニット名などで、ひらがなとカタカナを区別しなくなります。日本語版の Windows の元の SRC と同じく、大文字・小文字、全角・半角に加えて、ひらがな・カタカナも同じものとみなします（#1493）。
- **シナリオの設定ファイル**: シナリオのフォルダの `Src.ini`・`srcs.json` を読みます。そこにある項目はアプリの設定より優先し、プレイ中に設定を変えるとシナリオのファイルに書き戻します（#1451）。
- **端数の丸め**: 小数を整数にするとき、元の SRC と同じ偶数への丸めにしました（SRCCore の 705 か所。#1497）。小数のレベルの特殊能力・武器属性・アビリティ、スペシャルパワーの効果量、敵の思考、式の `\` 演算子などで値が変わります。最大霊力・最大ＳＰ・Recover 系の端数、ExpUp・LevelUp の後のＨＰ・ＥＮも元の SRC と同じ値になります（#1493・#1497）。
- **乱数の進み方**: 融合・迎撃・先制反撃の判定で、元の SRC と同じくサイコロを振るようにしました。同じ乱数の系列でも、命中などの結果が 3.5.6 と変わることがあります（#1507・#1509・#1528）。
- **武器・アビリティの一覧**: 元の SRC と同じ欄・並びにしました。武器は射程・必要気力の欄を出して攻撃力の順に並べ、アビリティは効果・射程・回数・EN・分類の欄を出します。援護攻撃をしてくれるユニットが隣にいるときは「援護攻撃：使用する／使用しない」の行を出します（#1493）。
- **ステータスウインドウ**: 能力値の配置、ＨＰ・ＥＮのゲージの位置と色、武器の並びを元の SRC に合わせ、必要条件を満たさない特殊能力を赤で出します。顔の絵をクリックすると、パイロット → サポート → 追加サポートの順に替わります（#1493・#1524・#1537）。
- **テロップ**: 枠の無い白い窓に、黒の太字斜体で書きます（#1537）。
- **イベントの順番と回数**: 接触イベントを左・右・上・下の順に、マップの四隅の脱出イベントを左右と上下の両方で起こします。再開イベントは、中断・クイックセーブ・リスタートのデータを読んで、マップや背景が変わったときだけ起こします（#1493）。
- **地形とレイヤー**: ChangeTerrain で変えた地形が、再開しても戻らなくなりました。背景は変えたマスだけを描き直します。ChangeLayer で画像が無ければエラーにします（#1493・#1512）。
- **ファイルのコマンド**: Open の出力モードは中身を消してから書きます。Print・Write の改行は CR+LF、LineRead でファイルの終わりを越えるとエラー、RemoveFolder は中身ごと消します（#1493）。
- **画像と MIDI の探し方**: シナリオ → 拡張データフォルダ → SRC のフォルダの順に探します。地形画像の `Bitmap\Map\plain\plain0001.bmp` のような名前、Midi のサブフォルダの曲も探します（#1493）。
- **描画**: FillStyle の模様、Arc の向き、PaintPicture の透過色、白黒・セピア・夕焼けなどの加工の計算を元の SRC に合わせました。地形ユニット・非表示のユニット・行動済みの網掛けの描き方も合わせました（#1493・#1512・#1537）。
- **並べ替え**: MakeUnitList・MakePilotList・Organize・ForEach・Sort・部隊表を、元の SRC と同じ並べ方にしました。値が同じものの順番が変わることがあります（#1519・#1522・#1528・#1531・#1537）。
- **中断データからの再開**: 特殊状態・効果中のスペシャルパワー・アビリティの残り回数・追加サポート・イベントラベルの有効と無効を戻します。クイックセーブの後の QuickLoad がリスタートのデータを読んでいたのを直しました（#1525・#1527・#1544）。
- **クリアデータの読み込み**: 一時的な他形態（変形の形態など）が消えなくなりました。シナリオの途中の SaveData コマンドで保存したデータでは、味方でないパイロットも元の SRC と同じく味方として残ります（#1581）。
- **メッセージ**: メッセージスピードを選べます（手動送り〜神の領域）。左ボタン（SRC#Avalonia・SRC#Web では Enter や仮想パッドの A も）を押し続けると、ウェイトごとにメッセージを送ります。Question の制限時間を 0.1 秒単位で数えます（#1493）。
- **数値の読み方**: `1e5` のような指数表記、`&H10`・`&O17`（符号なし）、`(1)`（-1）、`￥100`・`\100`、`1-`（-1）を数値として読みます。データに書いた `&H1000` も 4096 と読みます。`-0` は「0」と書きます。実行する環境の言語の設定にかかわらず、日本語の書式で読みます（#1544・#1558・#1580）。
- **Format**: `Medium Date` は `yy-mm-dd`、時刻（Long Time など）の終わりに空白、`ddd`・`mmm` は英語、令和は使わず平成のまま、空の書式は数値を数値として書きます。日付の書式に `0`・`#` を書くとエラーです（#1572・#1580）。
- **エラーにする所**: 計算の結果が無限大・非数になるとき（`10 ^ 400`・`Sqr(-1)` など）、文字列関数の範囲外の引数、RankUp・IncreaseMorale の範囲を超える値、引数の無いコマンドの引数を読むとき（Incr・Ride・Create など）は、元の SRC と同じく「イベントデータが不正です」にします（#1572・#1580・#1582）。
- **データの誤り**: 元の SRC と同じくダイアログに出し、元の SRC が読み込みを打ち切る誤りでは終了します。大文字・小文字だけが違う名前のパイロット、Lv の後が数値でない特殊能力などは、3.5.6 で読めていても打ち切りになります。lint の結果も同じく変わります（#1527・#1533・#1575）。
- **ポップアップメニュー**: マウスの位置を横の中心にして開きます。ユニットのコマンドはマウスの少し上から開きます（SRC#Avalonia・SRC#Web・SRC#Form。#1584）。

## 主な変更

- **元の SRC のセーブデータを読める**: 元の SRC で保存したクリアデータ・中断データ（`.src`）を開いて、続きを遊べます。書き出しは今までどおり SRC# の形式です（#1578・#1594、[SRCとの互換性](https://srch.7474.jp/SRCとの互換性/)）。
- **不具合の修正**
  - SRC#Avalonia で、シナリオが終わるとき（中断・ゲームクリア・Quit）に毎回アプリが落ちていたのを直しました。見た目はウィンドウが閉じるだけでした（#1598）。
  - SRC#Web で、中断すると「プロローグイベントが定義されていません」のエラーが出ていたのと、ゲームクリアの後も裏で処理が続いていたのを直しました（#1597）。
  - 括弧の閉じていない Ask の行があると、シナリオの読み込みが止まっていたのを直しました（#1583）。
  - Load コマンドで読み直すデータを元の SRC と同じ範囲にし、特殊効果のメッセージが重なって出ていたのを直しました（#1562）。
  - LoadFileDialog でシナリオのフォルダの中のファイルを選ぶと空が返っていたのを直しました（#1493）。
  - 全体マップの背景を元の SRC と同じ灰色にしました（#1573）。
- **SRC#Web**
  - タップしたマスにカーソルを置き、仮想パッドの A・B は 1 回で効くようにしました。マップのメニューを閉じた後の B の空振りを直しました（#1454）。
  - 仮想パッドの B を押し続けると、メッセージを飛ばします（#1455）。
  - 設定に「デバッグ」を加え、ログを画面の下に出せます（#1454）。
  - ブラウザの保存領域が使えないときなどの失敗を画面に出します。これまでは操作できなくなることがありました（#1453）。
  - データの誤りで読み込みを打ち切ったときは、エラーの報告を送りません（#1575）。
- **SRC#Avalonia・SRC#Web（SRCRender）**
  - 壊れた画像・対応しない形式の画像を元の SRC と同じくエラーで知らせ、「Now Loading ...」の画面に進み具合のバーを描きます（#1563）。
- **SRC#Form**
  - Enter・Esc をクリック・右クリックとみなすなど、元の SRC の操作を入れました（#1537）。
  - 一覧を開いたときに項目を選ばない、最初の一覧がウィンドウの中央に出る、戦闘のメッセージの「HP」「EN」が切れる、移動範囲の外の塗り方、中断から再開した後に一覧の窓が広がったままになる、を元の SRC に合わせて直しました（#1584・#1591・#1596）。
- **ヘルプ**
  - 元の SRC（Ver2.2.33）のヘルプを [アーカイブ](https://srch.7474.jp/vb/) として置きました。目次・キーワード・検索が使えます（#1445）。
  - 「SRC#Webの使い方」「SRC#Formの使い方」の頁を加え、メニューを並べ直しました（#1445）。
  - 元の SRC から移したままだった頁をすべて SRC# の実装と照らし合わせ、違いを「SRCとの互換性」にまとめました（#1458・#1576）。
  - 幅の狭い画面でクレジットが本文に重なるのを直し、頁の下に前後の頁へのリンクを付けました（#1496）。
- **NuGet**: パッケージにライセンスとリポジトリの URL を入れました（#1450）。3.5.6 は NuGet への公開に失敗していたので、信頼された発行（Trusted Publishing）に切り替えました（#1449）。
- **その他**
  - 元の SRC の 1,333 の手続きと SRC# の対応表を作り、すべて突き合わせました（#1497・#1506〜#1547・#1573）。参考用に残していた VB のコードを消しました（#1532）。
  - 移植の誤りを見つけるアナライザーを加えました（#1497・#1557）。
  - 互換性の検証用のデータパックとシナリオ（全 8 話）を新しく作り、CI で通しで流しています（#1559〜#1561・#1574・#1595）。
  - 元の SRC の実機で動かした結果（プローブ・画面と音・セーブデータ）を置き、SRC# と毎回比べるテストを加えました（#1564・#1565・#1580・#1584・#1585・#1591・#1592・#1594）。
  - CI で使う .NET の SDK を 10 に固定し、テストの乱数を固定しました（#1599）。
  - 依存パッケージを更新しました（#1448・#1457・#1514・#1517・#1538・#1539・#1542・#1567・#1587）。
