SRC# 3.5.8 です。アプリは `3.5.8`、ライブラリ・ツールと VS Code 拡張は `0.5.8` です（[バージョンの管理](https://github.com/7474/SRC/blob/master/docs/versioning.md)）。

.NET 11 に上げました。SRC#Form を使うには .NET 11 のデスクトップ ランタイムが、`srcsharp` と VS Code 拡張には .NET 11 の SDK が要ります。シナリオ・データを作る道具を大きく増やしました。ブラウザと VS Code で動く SRC#Studio（マップ作成ツール・かんたん作成・人形劇）、データのプレビューと試し戦闘、話のつながりの図などです。入口はヘルプの「[SRC#でシナリオ・データを作る](https://srch.7474.jp/SRCSharpでシナリオ・データを作る/)」です。

## 動きが変わる点

- **.NET 11**: SRC#Form を使うには、[.NET 11 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/11.0)（x64）を入れてください。.NET 10 のランタイムでは起動しません。`srcsharp`（`dotnet tool install -g SRCSharpTools`）と VS Code 拡張には、.NET 11 の SDK が要ります。SRC#Avalonia・SRC#Web はランタイムを含んでいるので、入れ直すものはありません（#1566）。
- **等幅の文字の並び**: SRC#Avalonia・SRC#Web で、等幅の指定（ＭＳ 明朝・ＭＳ ゴシック）の文字を、元の SRC と同じく Shift_JIS のバイト数の升目（半角 1・全角 2）に並べるようにしました。α・Ω・°・‘・£ などを含む行で、空白で揃えた桁がずれていたのが直り、これらの文字の位置が変わります（#1658、[SRCとの互換性](https://srch.7474.jp/SRCとの互換性/)）。
- **最小の汎用データ**: 地形の画像を描き直し、海・川・道路・林・山などに境目のチップを加えました。最小の汎用データで遊ぶと、既存のマップの見た目が変わります。宇宙・月面の地形（宇宙空間・暗礁空間・コロニー・月面など 12 種）も加えたので、これらの番号のマスは仮の地形ではなく正しい地形になります。元の汎用グラフィック集を使っている場合は変わりません（#1661・#1662・#1686）。
- **地形データが無いときの移動範囲**: 地形データ（`terrain.txt`）に無い番号のマスの仮の地形で、移動範囲が移動力の 2 倍になっていたのを直しました（#1674）。

## 主な変更

- **SRC#Studio**（ブラウザと VS Code。[SRC#でシナリオ・データを作る](https://srch.7474.jp/SRCSharpでシナリオ・データを作る/)）
  - **マップ作成ツール**: MapEdit.exe の代わりに、ブラウザと VS Code（`.map` を開く）でマップを描けます。描く・四角・塗りつぶし・スポイト・写す・貼る、レイヤー、元に戻す、大きさの変更ができ、Chrome・Edge ではフォルダを直接読み書きします。最小の汎用データでは、境目を自動でつなげます（#1645・#1686、[マップデータ](https://srch.7474.jp/マップデータ/)）。
  - **配置と人形劇**: `.eve` の `Create`・`Launch`・`Move` などで置くユニットをマップに出し、ドラッグで座標を書き換えます。援軍と `進入` の目標も出します。場面を一手ずつ進めて会話と動きを一緒に見る「人形劇」では、ユニットを動かすと `Move` を書き、「この場面を再生」でその場面だけを SRC#Web やデバッガで動かせます（#1678・#1695・#1696・#1702）。
  - **かんたん作成**: 作品（GSC データパック）を選んでユニット・パイロットを置き、セリフを書くと、同じサイトの SRC#Web ですぐ遊べます。ランク・ボスランク、勝利・敗北の条件、援軍・撤退・戦闘中の会話などの出来事、複数話のキャンペーンを作れます。zip は `srcsharp new` と同じ構成で保存し、VS Code で続きを書けます（#1660・#1665〜#1667・#1677・#1687・#1698・#1699）。
- **作成支援（VS Code 拡張・`srcsharp`）**
  - **ひな形**: `srcsharp new`（VS Code「SRC#: 新しいシナリオを作る」）で、最小の汎用データで遊べるシナリオ・自動プレイの手順・作者のリポジトリの CI を作ります。`--episodes` で複数話のひな形も作れます（#1646・#1680）。
  - **データのプレビューと試し戦闘**: ユニット・パイロットの能力値・武器などをエンジンと同じ読み方で出し、表で直せます（VS Code「SRC#: データのプレビュー」）。`srcsharp trial`（「SRC#: 試し戦闘」）で、データを直しながら敵と戦わせられます。戦闘のセリフ（`pilot_message.txt`・`pilot_dialog.txt`）の補完と、メッセージウィンドウでの見え方の確認もできます（#1647・#1679・#1682）。
  - **確かめる・見通す**: 話のつながりの図（`srcsharp flow`）、イベントの流れの図（`event-flow`）、会話の画像（`talk-preview`）、戦闘アニメ・特殊効果の再生（`anime-preview`）、素材が揃っているか（`assets`）、何回か自動で遊ぶ強さの確かめ（`playtest`）、出来事・変数・登場人物のまとめと気づいたこと（`outline`）を加えました。VS Code では同じことをコマンドで行い、気づいたことはエディタに「情報」として出します（設定 `srcsharp.outlineFindings`）（#1680・#1681・#1683・#1699・#1701・#1702）。
  - **出来事をフォームで書く**: きっかけ・会話・撤退をフォームで選んで出来事を足し、既存の出来事をフォームで直せます（`srcsharp event-text`、「SRC#: 出来事を足す」「SRC#: 出来事を直す」）。途中の話は、前の話までの状態か、手で決めた始めの値（`srcsharp start-state`）から遊べます（「SRC#: この話から遊ぶ」）（#1699・#1700・#1703）。
  - **エディタ**: イベントのデータの名前（ユニット・パイロット・アイテム）がデータに無ければ警告し、ホバー・定義へ移動・補完を付けました。コマンドのホバーにヘルプの説明を出し、データのファイルで特殊能力・武器の属性を補完します。ユニット・パイロット・変数・ラベルの名前を一括で変えられます（#1646・#1699）。
- **lint**: データの規則をグループで選べるようにしました（`srcsharp lint --rules`、既定は `src`。ほかに `gsc-robo`・`gsc-ext`・`robodun`）。VS Code ではデータのファイルにも診断を出します（設定 `srcsharp.rules`）。`src` の規則は「情報」で、終了コードには数えません（#1621・#1622）。
- **データビューア**
  - 「比べる」の頁を加えました。GSC データパックの組（パイロットとユニット）の評価を、ランキング・横並べ（4 組まで）・作品・位置で比べます。推定の組には印を付け、スマートフォンでも読めるようにしました（#1631・#1637）。
  - ユニット・パイロットのカードに「このデータをコピー」「VS Code で追加」を付けました（#1682）。
- **不具合の修正**
  - `srcsharp play` の自動プレイで、移動後の攻撃でシナリオが終わると誤って止まっていたのを直しました（#1674）。
  - PlayScript の `expect message` が、`auto` 以外の入力で進んだメッセージを見つけられないことがあったのを直しました（#1625）。
- **その他**
  - .NET 11 に上げ、依存パッケージを更新しました（#1566・#1602・#1603・#1669・#1675）。
  - 開発版（`dev`）を作るワークフローが失敗し続け、開発版が入れ替わっていなかったのを直しました（#1601）。
  - 開発者向けの文書（コンポーネントの構成・判断の記録）、汎用グラフィック集のマップチップの番号と意味のデータ、CI の警告の解消（#1620・#1624・#1630・#1638・#1647・#1648・#1664・#1697）。
