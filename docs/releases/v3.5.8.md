- **SRC#Web**
  - Studio: 人形劇の場面だけをエンジンで再生する（#1696）
- **データビューア**
  - データビューアに「比べる」の頁を足す（#1628・#1629）（#1631）
  - 比べる: 耐久力の頭打ち・推定の組の見分け・ユニット／パイロットだけの比較・スマートフォン表示（#1637）
  - feat(#1656): データビューアのデータコピー・VS Code連携と能力値・地形適応の表編集（#1682）
- **SRC#Form**
  - .NET 11 の正式版（11.0.0）に上げる（#1566）
- **本体（SRCCore・SRCRender・SRCSound）**
  - PlayScript の expect message で、auto 以外の入力で進んだメッセージも見つける（#1623）（#1625）
  - 等幅の指定の文字を Shift_JIS のバイト数の升目に並べ、空白で揃えた表示の崩れを直す（#1658）
  - srcsharp play の自動プレイ終了時停止と仮地形の移動コストを修正 (#1668)（#1674）
- **作成支援（srcsharp・lint・デバッガ）**
  - データの定義の場所を記録し、グループで管理する規則の仕組みを lint に入れる（#1609・#1610）（#1621）
  - lint の規則（src・gsc-robo・gsc-ext・robodun）を入れ、VS Code・ブラウザの lint に出し、試作を CI で守る（#1388）（#1622）
  - 作成の入口（ヘルプ・srcsharp new・CI のひな形）と LSP の拡充（データの名前の参照・コマンドのヘルプ）（#1646）
  - データのプレビュー・試し戦闘・表で直す・比べる（SRC#Studio と VS Code）（#1647）
  - かんたん作成: ランクとボスランク、場面の一覧は押して開く（#1666）
  - データ: メッセージ・ダイアログデータの作成支援（戦闘のセリフ）（7474/SRC#1651）（#1679）
  - feat: 複数話シナリオのひな形（--episodes）と話のつながりの図（srcsharp flow）(#1652)（#1680）
  - 素材: シナリオに必要な素材が揃っているかの管理 (#1654)（#1681）
  - feat(#1655): 会話・戦闘アニメ/特殊効果プレビューとイベントの流れの図（#1683）
  - Studio: 人形劇の編集（場面を一手ずつ見て Move を書く）（#1695）
  - かんたん作成: 出来事（勝敗の条件・援軍・戦闘中の会話・撤退）（#1698）
  - シナリオ作成の次の段: 強さの確かめ・かんたん作成の次の一歩・複雑なシナリオの支援（#1699）
  - 出来事をフォームで足す（srcsharp event-text・VS Code「出来事を足す」）（#1700）
  - 話のつながりの図に加入・離脱、マップに援軍・目標を重ねる（#1702）
  - 出来事をフォームで直す・途中の話を手で決めた始めの値から遊ぶ（#1703）
- **VS Code 拡張**
  - マップ作成ツール（SRC#Studio）をスタンドアロンの Web アプリと VS Code 拡張で動かす（#1645）
  - マップエディタ・VS Code にイベント配置の表示と座標編集を追加 (#1653)（#1678）
  - 見通しの気づいたことをエディタの診断に出す（#1701）
- **CI**
  - 開発版を作る Packages が失敗し続けていたのを直す（lint の確かめのデータ）（#1601）
- **文書**
  - データ検証の補強を規則の検査に絞り、規則をグループで管理する計画を判断の記録に書く（#1388）（#1620）
  - データ検証の補強の判断の記録に結果を書き、完了とする（#1388）（#1624）
  - データの比較を楽しむための道具として整える計画と、組の評価の JSON を書く（#1607・#1626）（#1630）
  - 作成環境の補完の判断の記録を完了にする（#1648）
  - SRC#Studio にかんたん作成を足し、作ったシナリオを同じサイトの SRC#Web ですぐ遊べるようにする（#1660）
  - 最小の汎用データに宇宙・月面の地形と画像を足す（#1661）
  - 汎用グラフィック集のマップチップの番号と意味をデータにする（#1664）
  - SRC#Studio: 画面の使い勝手を見直す（#1665）
  - SRC#Studio かんたん作成のリセット導線と下書きクリアを改善（#1677）
  - feat(map-chips): 最小の汎用データのマップチップ刷新・自動接続・VRT・ADR を追加 (#1663)（#1686）
  - SRC#Studio: 表で直すの入力が消える不具合、素材の一覧のスマホ表示、画像の案内（#1687）
  - Docs: 作成支援の機能の記載を揃える（#1697）
- **その他**
  - CI の警告を消す（MSTEST0044・E2E の取り直しの時間切れ）（#1638）
  - 月面の地形の画像が月面基地の絵になっていたのを直す（#1662）
  - かんたん作成: 縮図と盤面の画像を並行に読む（#1667）
- **依存パッケージの更新**（#1602・#1603・#1669・#1675）
