SRC# 3.5.1 です。アプリは `3.5.1`、ライブラリ・ツールは `0.5.1` です。v0.5.0 以降の変更をまとめたリリースで、今回からタグをアプリのバージョン（`v3.x.x`）で打っています（[バージョンの管理](https://github.com/7474/SRC/blob/master/docs/versioning.md)）。

## 遊ぶ

| | 入手 |
|---|---|
| ブラウザ | **SRC#Web** https://7474.github.io/SRC/web/ 。自分のサイトに置くための `SRCSharpWeb.zip` も添付しています（[外部のサイトに置く](https://github.com/7474/SRC/blob/master/docs/gui/web-hosting.md)） |
| Windows・macOS・Linux | **SRC#Avalonia**（新規） |
| Windows（x64） | **SRC#Form** `SRCSharpForm.zip`（[.NET 10 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/10.0) の x64 版が必要） |

## 主な変更

- **SRC#Avalonia（新規）**: Windows・macOS・Linux で動くフロントエンドです。画面の描画は、UI フレームワークに依存しない `SRCRender`（SkiaSharp）が受け持ちます。MIDI は SoundFont で合成します。
- **SRC#Web（新規）**: ブラウザで動く版です（マルチスレッドの WebAssembly）。主な機能は次のとおりです。
  - セーブデータをブラウザに保存する
  - タッチ操作と仮想キー
  - シナリオの zip の読み込み、外部のサイトへの設置
- **多言語対応**: 画面の文字列を 15 の言語に切り替えられます。既定は日本語です（[多言語対応](https://github.com/7474/SRC/blob/master/docs/i18n.md)）。
- **作成支援ツール**
  - `srcsharp`（.NET tool、NuGet の `SRCSharpTools`）を初めて公開しました。データの lint、シナリオの自動プレイ、バランス集計、Language Server、イベントのデバッガがあります。入れるには `dotnet tool install -g SRCSharpTools` を実行します。
  - VS Code 拡張 [koudenpa.src-vscode](https://marketplace.visualstudio.com/items?itemName=koudenpa.src-vscode) 0.5.0 をプレリリースで公開しました。`src-vscode-0.5.0.vsix` も添付しています。
- **移植の修正**: 元の SRC と挙動が違っていた点を多数直しました。主なものは、イベントの処理、召喚ユニット、暴走時パイロット、追加パイロットの経験値、ECM の範囲などです。
- **テスト**: シナリオをヘッドレスでプレイする E2E テストと、画面の VRT を CI で実行しています。
