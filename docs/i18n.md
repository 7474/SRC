# 多言語対応

SRC# の画面の文字列（ダイアログのタイトルやボタンなど）は、日本語を既定として英語に切り替えられる。

## 仕組み

- .NET の標準の仕組み（`.resx` リソース・`System.Resources.ResourceManager`・`CultureInfo.CurrentUICulture`）を使う。
- 各プロジェクトの `Resources/Strings.resx` が既定（ニュートラル）の日本語、`Resources/Strings.en.resx` が英語。csproj で `NeutralLanguage` を `ja` にしている。英語はサテライトアセンブリ（`en/<アセンブリ名>.resources.dll`）になる。
- コードからは手書きの静的クラス `Strings`（キーごとのプロパティ）で参照する。SRCRender では `SRCCore.VB.Strings` と名前が重なるため `SRCRender.Resources.Strings` に置いている。
- 言語の設定は `SRCRender.UiLanguage.Apply(string)` で行う。設定するのは UI カルチャ（`CurrentUICulture` と `DefaultThreadCurrentUICulture`）だけで、数値の書式などに関わる `CurrentCulture` は変えない。

## 言語の指定

| 値 | 表示 |
| --- | --- |
| 空・未指定・`ja` | 日本語（既定。OS の言語によらない） |
| `en` | 英語 |
| `auto` | OS の UI の言語に従う（訳の無い言語は日本語） |

解釈できない値は日本語として扱う。

## SRC#Avalonia

設定ファイル `srcs.json`（実行ファイルと同じフォルダ）の `Option` セクションの `Language` 項目で指定する。

```json
{
  "Sections": [
    {
      "Name": "Option",
      "Items": [
        { "Name": "Language", "Value": "en" }
      ]
    }
  ]
}
```

起動時（シナリオ選択のダイアログを出す前と、`ScreenSession` が設定を読んだ直後）に反映する。変更は次回の起動から有効になる。ゲーム内の設定変更ダイアログには項目を設けていない。

## 訳さない文字列

次のものはシナリオやデータと結びついているため、表示言語によらず日本語のままにする。

- SRC のキーワード・データの値（陣営の「味方」「敵」、特殊能力名、地形、描画オプションの「白黒」「透過」など）。シナリオやエンジンが文字列として比較する。
- `Expression.Term(...)` で得る用語。シナリオが名称を変えられる。
- コマンド名・`CommandState` の値・リストボックスのモード指定など、エンジン内部の状態として比較する文字列。
- ステータスウィンドウやリストの見出しにある元の SRC のゲーム用語（ＨＰ・ＥＮ・装甲・運動性など）。
- フォント名（ＭＳ Ｐゴシックなど）と、「システム」などのシナリオのメッセージ。

表示文字列を状態として比較していた箇所（メッセージウィンドウの自動送りの判定、出撃選択の並べ替えボタン）は、訳しても動作が変わらないようにフラグで判定している。

## 言語を追加するには

1. 各プロジェクトの `Resources/Strings.resx` を複製して `Resources/Strings.<カルチャ名>.resx`（例: `Strings.ko.resx`）を作り、`value` を訳す。キーはすべて揃える（SRCRenderTests の `UiLanguageTests` で英語のキーの揃いを確かめている）。
2. csproj の `SatelliteResourceLanguages` にカルチャ名を加える。
3. 設定の `Language` にそのカルチャ名を指定する。
