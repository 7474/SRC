# 判断の記録 / Decision Records

設計・運用で何を決めたか、なぜそうしたかの記録です。現在の状態は各ドキュメント（[一覧](../README.md)）に書き、ここには背景・判断・理由・影響を残します。

## 書き方

- ファイル名は `YYYY-MM-DD-<英語の短い名前>.md`。日付は判断した日
- 見出しは「日付」「状態」「背景」「判断」「理由」「影響」「参照」
- 判断を変えたときは、元の記録は消さずに「状態」を「置き換え済み」にし、後継の記録へのリンクを書く
